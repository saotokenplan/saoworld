# 任务验收清单

本清单用于约束本次“最近 7 天 Git 活动分析”输出质量。

---

## 一、基础校验

| 序号 | 校验项 | 通过标准 |
|------|-------|---------|
| 1.1 | 时间窗口明确 | 统计范围清晰说明为最近 7 天 |
| 1.2 | 数据来源真实 | 仅使用 Git 历史、仓库文件与命令输出 |
| 1.3 | 输出结构完整 | 至少覆盖模块分布、核心文件、主要主题、潜在热点 |
| 1.4 | 无编造 | 不能从证据确认的内容标记为“待验证” |
| 1.5 | 语言一致 | 最终输出为中文 |

---

## 二、内容完整性校验

| 序号 | 校验项 | 通过标准 |
|------|-------|---------|
| 2.1 | 提交概览完整 | 包含提交数、作者或提交活跃概况 |
| 2.2 | 目录分布完整 | 给出热点目录或模块分布统计 |
| 2.3 | 核心文件可追溯 | 核心文件来自真实变更频次或关键提交 |
| 2.4 | 主题归纳有依据 | 主要主题至少能回溯到提交标题或文件集合 |
| 2.5 | 潜在热点谨慎 | 热点仅基于频次、覆盖度或改动集中度判断 |

---

## 三、结果可交付性校验

| 序号 | 校验项 | 通过标准 |
|------|-------|---------|
| 3.1 | 结论可复核 | 关键结论附有统计口径或代表性证据 |
| 3.2 | 表达可扫描 | 结论分组清晰，适合快速阅读 |
| 3.3 | 边界清楚 | 明确哪些是事实统计，哪些是谨慎推断 |
| 3.4 | 风险提示充分 | 指出潜在热点时附带不确定性说明 |
| 3.5 | 禁止编造落实 | 若无法确定，明确写“待验证”或“不足以下结论” |

---

## 四、终止条件

- 基础校验、内容完整性、结果可交付性三类检查均满足
- 不存在无法追溯来源的关键结论
- 用户要求的 4 个输出维度全部覆盖
