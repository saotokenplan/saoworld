## B. 本周执行状态分析

- [ ] 已识别当前 Sprint 阶段目标
- [ ] 已对照计划任务与实际完成情况
- [ ] 已统计已完成任务数量与占比
- [ ] 已统计进行中任务数量与占比
- [ ] 已统计未开始任务数量与占比
- [ ] 已评估本周计划完成情况与实际偏差
- [ ] 已识别阻塞问题、跨团队依赖、资源冲突与潜在风险
- [ ] 已判断是否存在需求蔓延、优先级错位或关键任务滞后
- [ ] 已评估核心需求完成率与里程碑达成情况

## C. 迭代方向评估

- [ ] 已对比 Sprint 目标、产品战略与本周实际进展
- [ ] 已给出迭代方向结论：正常 / 需关注 / 偏离
- [ ] 已记录判断依据
- [ ] 已给出纠偏建议（如需要）
- [ ] 已重新判断下周任务优先级是否需要调整
- [ ] 已明确下周工作重心与主线价值交付

## D. 后续迭代规划

- [ ] 已评估当前迭代完成率是否接近完成阈值
- [ ] 已判断核心链路任务是否基本完成
- [ ] 若接近完成，已规划下一周或下一迭代重点工作
- [ ] 后续规划已覆盖核心目标、关键任务、前置依赖、验收信号
- [ ] 后续规划体现渐进式价值交付、主链路优先与风险收敛

## E. 文档与报告产出

- [ ] 已更新 `docs/00-governance/project-status.md`
- [ ] 已检查 `docs/40-dev-loop/weekly-report-2026-09-12.md` 是否存在
- [ ] 若周报不存在，已生成周报
- [ ] 若周报已存在，已跳过生成并给出简要状态
- [ ] 周报已包含整体状态指标与 Sprint 进度百分比
- [ ] 周报已包含本周完成 / 进行中 / 未开始任务
- [ ] 周报已包含关键成果、问题风险、偏差分析与调整建议
- [ ] 周报已包含下周重点任务建议
- [ ] 若当前迭代接近完成，周报已包含后续任务规划
- [ ] 若触发月报条件，已生成 `monthly-report-2026-09-12.md`
