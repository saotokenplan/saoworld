# Weekly Code Review Checklist

> 任务名称：每周代码审查与重构优化
> 日期：2026-09-05
> 状态：待确认

## A. 输入完整性

- [ ] 已确认统计窗口为最近 7 天（2026-08-29 至 2026-09-05）
- [ ] 已收集最近 7 天 Git 提交记录
- [ ] 已汇总最近 7 天变更目录与核心文件
- [ ] 已确认 `services/`、`workers/`、`game/`、`tools/`、`docs/` 的周变更范围
- [ ] 已读取 `docs/10-requirements/需求迭代计划.md`
- [ ] 已读取 `docs/10-requirements/项目里程碑与验收标准.md`
- [ ] 已读取 `.trae/rules/10-python-backend.md`
- [ ] 已读取 `.trae/rules/41-testing.md`
- [ ] 已读取与热点模块直接相关的其他规范
- [ ] 已读取 `docs/00-governance/project-status.md`（若存在）
- [ ] 已读取最近一份 `docs/40-dev-loop/weekly-report-*.md`（若存在）

## B. 分析产出

- [ ] 已总结本周主要改动模块
- [ ] 已总结本周主要功能点与缺陷修复点
- [ ] 已总结本周技术债热点
- [ ] 已识别热点是否集中在 API / Repository / 领域模型 / 异步任务 / 客户端 / 测试基建
- [ ] 已输出本周改动概览
- [ ] 已给出风险区域判断
- [ ] 已识别可能的结构性问题

## C. 六维评审

- [ ] 已完成架构一致性分析
- [ ] 已完成可读性分析
- [ ] 已完成可靠性分析
- [ ] 已完成稳定性分析
- [ ] 已完成可测试性分析
- [ ] 已完成可维护性分析
- [ ] 每个关键问题均记录影响范围
- [ ] 每个关键问题均记录严重程度
- [ ] 每个关键问题均给出建议处理方式

## D. 重构决策

- [ ] 已将优化项拆分为“立即实施 / 建议纳入下周 / 暂缓处理”
- [ ] “立即实施”项均满足高价值、低风险、可验证
- [ ] 未把无法确认安全性的项强行落地
- [ ] 已为涉及业务代码的修改声明对应测试更新要求
- [ ] 已确认本轮不会进行无边界大规模重写

## E. 执行与验证

- [ ] 若实施代码修改，已同步更新相关测试 / 文档 / 配置说明
- [ ] 已运行与改动范围直接相关的静态检查
- [ ] 已运行与改动范围直接相关的类型检查
- [ ] 已运行与改动范围直接相关的单元测试
- [ ] 若需要，已补充最小必要回归测试
- [ ] 若验证失败，已修复或明确回退策略
- [ ] 已检查编辑文件的诊断或语法问题

## F. 沉淀与交付

- [ ] 已沉淀可复用的规范、检查清单或 skills 草案
- [ ] 已生成或更新 `docs/40-dev-loop/weekly-code-review/weekly-code-review-2026-09-05.md`
- [ ] 已更新 `docs/00-governance/project-status.md`
- [ ] 报告中已包含测试与验证结果
- [ ] 报告中已包含风险与回滚说明
- [ ] 报告中已包含下周建议治理方向
- [ ] 若执行了代码修改，已按规范完成 git 提交
- [ ] 若执行了代码修改，已确认推送策略与分支状态

## G. Git 与交付前提

- [ ] 已确认当前应直接在 `feature-prd` 上提交，或已获得创建临时分支再回合并的明确指令
- [ ] 已确认是否需要执行“提交后推送、再合并、再删除分支”的完整 Git 流程
