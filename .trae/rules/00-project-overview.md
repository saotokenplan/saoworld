# 00 - 项目概览

> 适用角色：全员
> 本文件定义项目核心定位、核心玩法闭环、任务完成标准以及快速启动命令。

## 项目定位

这是一个**玩家投票驱动、AI持续生成内容**的大型开放式在线游戏项目。

- **一句话定义**：由玩家集体决定世界走向、由 AI 持续生成世界内容的大型开放式在线游戏
- **核心玩法闭环**：探索 → 参与 → 投票 → 世界更新 → 再探索
- **仓库模式**：单仓模式（Monorepo），包含文档、客户端、后端服务、异步任务、基础设施

## 核心价值

| 方向 | 价值说明 |
|------|----------|
| 开放世界 | 提供持续探索的空间，让玩家始终有新的区域、新的冲突和新的秘密可发现 |
| AI 生成 | 解决大规模内容生产成本问题，让世界更新频率更高、变化更多 |
| 玩家投票 | 让玩家真正参与世界治理，提升长期参与感和社区讨论度 |
| 持续演化 | 把游戏从一次性内容消费，转变为长期共同塑造的世界体验 |

## AI 职责边界

- **AI 负责**：可变内容生成（NPC、支线、聚落、局部事件）
- **AI 不负责**：主线终局、核心经济、底层战斗规则、世界观根设定

## MVP 范围（首期）

- 1 个核心常驻区域
- 1 个扩展区域
- 1 条主线骨架
- 3 个候选剧情方向
- AI 生成 NPC / 支线 / 局部事件 / 聚落描述
- 周期性投票系统
- 基础规则审核与人工复核
- 一次完整灰度发布与回滚演练

## 任务完成定义（DoD）

一个任务只有**同时满足**以下条件才算完成：

1. **需求范围实现完毕** - 功能按规范要求实现
2. **验收条件具备自动化信号** - 可通过测试或门禁验证
3. **相关测试与门禁已更新** - 单元测试/集成测试覆盖
4. **文档或配置同步更新** - 相关文档、配置、示例已同步
5. **回滚路径清晰可验证** - 如有变更，回滚方案明确

## 快速启动命令

```bash
# 启动本地基础设施（PostgreSQL 16 + Redis 7）
cd infra && docker compose -f docker-compose.dev.yml up -d

# 运行 vote-service
cd services/vote
pip install -e ".[dev]"
uvicorn app.main:app --reload

# API 文档（debug模式）
# http://localhost:8000/docs
# http://localhost:8000/redoc

# 运行测试
pytest

# 代码检查
ruff check .
mypy app
```
