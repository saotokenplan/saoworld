# Loop Engineering 标准工作流技能

本技能封装完整的循环工程方法论，让 AI 自动执行分层嵌套循环、三级校验、自动修复闭环。

## 适用场景

| 场景类型 | 触发条件 | 典型任务 |
|---------|---------|---------|
| 调研报告类 | 用户描述调研需求、需要收集信息 | 行业调研、竞品分析、技术选型 |
| 数据分析类 | 涉及数据清洗、计算、可视化 | 数据报表、业务分析、趋势预测 |
| 文档撰写类 | 需要生成结构化文档 | 方案文档、总结报告、技术文档 |
| 综合任务类 | 涉及多个阶段的复杂任务 | 项目规划、年度总结、战略分析 |

## 触发关键词
- "调研"、"收集"、"分析"
- "撰写"、"生成"、"报告"
- "整理"、"汇总"、"方案"
- "多轮"、"迭代"、"循环"

## 一、技能加载后的自动行为

### 1. 规划阶段（Plan 模式）
加载本技能后，AI 自动执行：

```
接收需求 → 读取模板 → 生成task-plan.md → 生成checklist.md → 等待用户确认 → 确认后启动循环
```

**自动生成的规划文档包含**：
- 6大标准阶段划分
- 每阶段调用的 Subagent
- 文件白名单范围
- 异常处理流程
- 28项验收标准

### 2. 执行阶段（三层循环）
用户确认后，自动启动三层嵌套循环：

```
主循环 (SOLO Agent)
    ↓ 调度
阶段子循环 (Subagent: researcher/writer/verifier)
    ↓ 修复
微修复循环 (Subagent: micro-fixer)
```

### 3. 校验阶段（三级流水线）
每阶段自动触发校验：
- L1：每次工具调用后 Hook 自动校验
- L2：子循环结束调用 verifier
- L3：主循环结束全量终验

### 4. 修复阶段（自动闭环）
校验发现缺陷自动启动修复：
- 写入 defect-report.md
- 分类缺陷 → 选择修复层级
- 启动对应修复循环
- 复测 → 通过放行 / 不通过继续
- 3次失败 → 上报人工

## 二、标准执行流程

### 流程1：调研报告任务
```
1. 加载 loop-workflow 技能
2. 自动生成 task-plan.md + checklist.md
3. 用户确认规划
4. 调用 stage-researcher 执行调研子循环
   - 搜索资料 → 整理汇总 → 去重校验
5. 调用 stage-writer 执行撰写子循环
   - 按模板分段撰写 → 自检内容
6. 调用 verifier 执行校验子循环
   - 对照 checklist 打分 → 生成缺陷报告
7. 发现缺陷 → 调用 micro-fixer 微修复
8. 复测通过 → 输出终稿
9. 全量审计日志 → 任务完成
```

### 流程2：技术方案任务
```
1. 加载 loop-workflow 技能
2. 自动生成规划（含技术调研阶段）
3. 调用 stage-researcher 技术调研
4. 调用 stage-writer 撰写方案文档
5. verifier 校验（含技术可行性检查）
6. 修复 → 终稿 → 交付
```

### 流程3：代码开发任务
```
1. 加载 loop-workflow 技能
2. 自动生成规划（含编译/测试校验）
3. 代码生成子循环
4. 编译/测试校验子循环
5. 缺陷修复微循环
6. 终验 → 交付
```

## 三、关键约束规则

加载本技能时，AI 必须遵守以下约束：

### 规划约束
- 必须生成 task-plan.md 和 checklist.md
- 必须等待用户确认才执行
- 规划内容必须包含6大阶段

### 执行约束
- 主循环上限：12轮
- 子循环上限：6轮
- 微修复上限：3轮
- 达到上限必须上报人工

### 校验约束
- 每轮循环必须对照 checklist 打分
- 总分 < 54分 必须启动修复
- 校验结果必须写入 verification-report.md

### 输出约束
- 所有信息必须标注来源
- 禁止编造数据或结论
- 无法获取的信息标注"待补充"

## 五、技能进阶用法

### 1. 自定义阶段
用户可修改 task-plan.md 增减阶段：
- 增加：增加数据校验阶段、增加可视化阶段
- 减少：调研已完成时跳过调研阶段

### 2. 自定义验收项
用户可修改 checklist.md 增减校验项：
- 增加：业务专属校验项（合规检查、品牌规范）
- 减少：简化格式校验项

### 3. 并行多循环
可同时启动多个独立循环：
- AgentA：调研报告循环
- AgentB：数据分析循环
- AgentC：文档撰写循环

|---------|-----------------|------|

| 内容生成 | stage-writer | 文档撰写 |
| 校验审查 | verifier | 质量检查 |
| 缺陷修复 | micro-fixer | 局部修复 |

## 七、技能配置

用户可在技能面板中配置：
- 启用/禁用自动规划生成
- 启用/禁用自动校验
- 调整循环迭代上限
- 添加项目专属模板
