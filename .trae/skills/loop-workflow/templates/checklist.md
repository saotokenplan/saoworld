# 任务验收清单

本清单为循环唯一终止标准。AI 每轮循环结束自动对照打分，满分才结束主循环。

---

## 一、基础格式校验（L1 - 轻量即时校验）

| 序号 | 校验项 | 校验方法 | 通过标准 |
|------|-------|---------|---------|
| 1.1 | 文件是否成功创建 | 文件存在检查 | 文件存在且大小 > 0 |
| 1.2 | Markdown 标题结构 | 检查 H1/H2/H3 | 至少包含三级标题 |
| 1.3 | 无空章节 | 内容长度检查 | 每个标题下有实质内容 |
| 1.4 | 无失效链接 | 检查所有链接 | 链接目标存在或 URL 有效 |
| 1.5 | 无语法错误 | Markdown 语法检查 | 无未闭合的代码块、表格 |
| 1.6 | 文件编码正确 | 编码检查 | UTF-8 编码 |
| 1.7 | 无多余空白 | 检查连续空行 | 连续空行 ≤ 2行 |
| 1.8 | 表格格式正确 | 检查表格语法 | 所有表格有标题行、对齐符 |

**L1 校验总分**：8项，每项1分，满分8分。

---

## 二、内容完整性校验（L2 - 阶段校验）

| 序号 | 校验项 | 校验方法 | 通过标准 |
|------|-------|---------|---------|
| 2.1 | 覆盖需求全部要点 | 对照原始需求逐项检查 | 每个需求点有对应内容 |
| 2.2 | 段落逻辑连贯 | 阅读全文检查 | 段落之间有过渡、无跳跃 |
| 2.3 | 核心数据完整 | 检查关键数据项 | 所有必需数据项已填写 |
| 2.4 | 图表/表格齐全 | 检查附件引用 | 所有声明图表已存在 |
| 2.5 | 引用来源标注 | 检查引用格式 | 所有数据来源有引用 |
| 2.6 | 无编造信息 | 逐项验证来源 | 所有信息可追溯到来源 |
| 2.7 | 参考附件覆盖 | 对照上传附件列表 | 相关附件内容已整合 |
| 2.8 | 版本信息准确 | 检查时间、版本号 | 与实际一致 |
| 2.9 | 术语一致性 | 全文术语检查 | 相同概念用相同术语 |
| 2.10 | 无重复内容 | 相似度检查 | 无高度重复段落 |

**L2 校验总分**：10项，每项2分，满分20分。

---

## 三、业务逻辑正确性校验（L3 - 全局终验校验）

| 序号 | 校验项 | 校验方法 | 通过标准 |
|------|-------|---------|---------|
| 3.1 | 数据前后一致性 | 跨文档数据对比 | 同一数据在不同位置一致 |
| 3.2 | 计算逻辑正确 | 复核关键计算 | 计算结果与公式一致 |
| 3.3 | 业务规则合规 | 对照业务规范检查 | 不违反已知业务约束 |
| 3.4 | 时序逻辑正确 | 检查时间相关描述 | 时间顺序合理、无矛盾 |
| 3.5 | 因果关系清晰 | 检查推论部分 | 推论有依据、无逻辑跳跃 |
| 3.6 | 风险点已识别 | 检查风险章节 | 已列出主要风险及应对 |
| 3.7 | 建议可执行 | 检查建议部分 | 建议具体、有责任人、有时间 |
| 3.8 | 格式统一 | 全文格式检查 | 字体、样式、排版统一 |
| 3.9 | 可交付性 | 检查完整度 | 可直接交付给目标受众 |
| 3.10 | 循环审计完整 | 检查 loop-log 目录 | 完整记录循环轨迹 |

**L3 校验总分**：10项，每项3分，满分30分。

---

## 四、验收总分计算

| 校验层级 | 项目数 | 单项分值 | 满分 |
|---------|-------|---------|------|
| L1 基础格式校验 | 8 | 1分 | 8分 |
| L2 内容完整性校验 | 10 | 2分 | 20分 |
| L3 业务逻辑正确性校验 | 10 | 3分 | 30分 |
| **总分** | **28** | - | **58分** |

**循环终止条件**：
- 总分 ≥ 54分（93%通过率）且 L3 无单项0分 → 正常终止
- 总分 < 54分 → 自动启动优化修复子循环
- 达到最大迭代轮次 → 异常终止，上报人工
