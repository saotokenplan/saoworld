## 二、异常处理子流程

### 1. 循环溢出处理
- **触发条件**：达到阶段最大迭代次数仍未通过校验
- **处理流程**：
  1. 暂停当前子循环
  2. 写入 `overflow-report.md` 记录溢出原因
  3. 回退主循环，评估是否需要调整策略
  4. 若主循环也达到上限，上报人工审核

### 2. 数据错误处理
- **触发条件**：发现数据源缺失、数据格式异常、数据不一致
- **处理流程**：
  1. 启动数据修复微循环（仅针对错误数据块）
  2. 记录错误详情到 `data-errors.md`
  3. 尝试从备用数据源补充
  4. 若无法修复，标注"待补充"并继续其他流程

### 3. 资料不足处理
- **触发条件**：关键信息无法找到可靠来源
- **处理流程**：
  1. 记录缺失信息清单到 `missing-info.md`
  2. 尝试扩展搜索范围、更换搜索关键词
  3. 若仍无法获取，标注"需人工补充"
  4. 在产出物中明确标注该部分为"待补充"

## 三、风险点识别与预防

| 风险类型 | 风险描述 | 预防措施 |
|---------|---------|---------|
| 信息编造风险 | AI 可能编造不存在的数据或引用 | 强制规则约束来源标注、Hook 校验 |
| 循环卡死风险 | 校验反复失败导致无限循环 | 迭代上限锁死、死循环检测 |
| 文件越权风险 | 修改不该修改的配置文件 | 黑名单拦截、Hook 前置校验 |
| 上下文溢出风险 | 长任务导致模型遗忘目标 | 分段执行、中间结果落地 |
| 数据丢失风险 | 清洗过程误删重要数据 | 原始数据备份、操作日志记录 |
