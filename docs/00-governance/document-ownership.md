# 文档归属与维护责任

> 文档状态：active
> 适用阶段：当前
> 维护要求：持续维护

## 目的

本文档用于明确不同层级文档的维护责任、裁定责任、协同更新责任和通知范围，减少“文档有人写但无人维护”“路径变更后没人同步”“跨层冲突无人拍板”的问题。

## 适用范围

- 适用于 `docs/` 目录下的全部文档。
- 适用于 `.trae/skills/` 中引用 `docs/` 路径的同步更新。
- 适用于新增、修订、迁移、重命名和删除等文档变更。

## 当前定位

- 本文档是文档维护责任与裁定关系的正式说明，用于回答“谁负责维护、谁负责拍板、谁需要协同”。
- 本文档聚焦责任分配和通知边界，不替代目录规则、变更步骤或具体评审清单。
- 当文档变更跨层级、跨目录或影响 `.trae/skills/` 引用时，应以本文档确认责任归属后再执行。

## 责任模型

本文档采用“按角色归属”而不是“按具体人名归属”的方式，避免人员变动后规则失效。

- 维护责任人
  - 负责日常修订、过期内容清理、引用同步和入口更新。
- 裁定责任人
  - 当多份文档冲突、跨层边界不清或是否合并存在争议时，负责最终裁定。
- 协同责任人
  - 当变更会影响上下游文档、接口样例、Skill 映射或流程治理时，负责同步参与评审。
- 通知对象
  - 不是每次都要审批，但当变更影响其使用或维护范围时，应被同步知会。

## 角色定义

- 产品规范责任人
  - 负责产品目标、玩法闭环、MVP 边界、验收口径相关文档。
- 技术规范责任人
  - 负责服务边界、数据模型、工程约束、接口契约相关文档。
- 流程治理责任人
  - 负责目录规范、变更流程、评审清单、闭环治理和协作方式相关文档。
- 内容与审核责任人
  - 负责内容生成、审核规则、发布与回滚约束相关文档。
- Skill 维护责任人
  - 负责 `.trae/skills/` 与 `20-specs/` 的映射一致性，不得自行反向定义上游规范。

## 变更时的责任分配

### 新增文档

- 发起新增的一方先判断文档层级，并承担首版草拟责任。
- 若新增的是入口型、治理型或映射型文档，流程治理责任人必须参与评审。
- 若新增内容包含执行约束，技术规范责任人必须确认其是否应进入 `20-specs/`。

### 修订文档

- 日常修订由对应目录的维护责任人处理。
- 若修订会改变权威关系、目录结构或阅读顺序，需同步流程治理责任人。
- 若修订会改变产品范围、接口行为、数据模型或审核规则，需同步对应上游规范责任人。

### 迁移与重命名

- 迁移前先由流程治理责任人确认目标目录是否正确。
- 执行迁移的人负责完成同主题内的路径修复和入口修复，不得把引用同步留到后续。
- 涉及 `.trae/skills/` 规范来源路径时，Skill 维护责任人负责完成同步。

### 删除文档

- 删除前必须由该文档的裁定责任人确认“已废弃”或“已被替代”。
- 删除执行人负责清理入口、映射和跨文档引用。
- 若删除的是入口型文档，流程治理责任人必须参与确认。

## 冲突裁定规则

- `10-requirements/` 与 `20-specs/` 冲突时，以 `20-specs/` 为准，由技术规范责任人裁定。
- `30-api/` 与 `20-specs/` 冲突时，以 `20-specs/` 为准，由技术规范责任人裁定。
- `40-dev-loop/` 与当前工程现状冲突时，由流程治理责任人裁定是否标记为“目标态”而非“当前可执行”。
- `.trae/skills/` 与 `docs/20-specs/` 冲突时，以 `docs/20-specs/` 为准，由对应上游规范责任人裁定。
- `00-governance/` 内部文档互相冲突时，以目录规范、变更流程和文档地图三者的最新一致口径为准，由流程治理责任人裁定。

## 默认通知规则

出现以下情况时，除直接修改文档外，还应同步通知相关责任人：

- 更新 `20-specs/` 中的执行约束
  - 通知 Skill 维护责任人和 `30-api/` 维护责任人。
- 更新 `30-api/` 中的接口行为、权限或错误码
  - 通知技术规范责任人和相关服务实现方。
- 更新 `00-governance/` 中的目录、流程或入口
  - 通知全部一级目录维护责任人。
- 迁移目录或批量改路径
  - 通知流程治理责任人、Skill 维护责任人和受影响目录责任人。
- 删除或合并已有文档
  - 通知该文档的裁定责任人和所有被引用方。

## 最小执行要求

- 每份新增文档至少能回答“谁维护、与哪层文档相关、变更时谁需要知道”。
- 每次结构性变更至少检查一次：
  - `docs/README.md`
  - `docs/00-governance/document-map.md`
  - `.trae/skills/` 中的相关引用
- 若当前没有明确的具体人员分工，至少要先按本文档定义的角色完成责任归属，再开始批量新增或迁移文档。
