# 需求背景入口

> 文档状态：active
> 适用阶段：当前
> 维护要求：持续维护

## 目的

本目录作为 `docs/10-requirements/` 的统一入口，用于汇总项目的需求背景、产品讨论、方案草案和里程碑信息，帮助读者理解“为什么做、希望做成什么”。

## 适用范围

- 适用于快速了解项目目标、核心玩法、MVP 边界和需求演进背景。
- 适用于产品、策划、研发在进入执行规范前建立共同上下文。
- 不替代 `20-specs/` 的实施约束、验收基线和工程规则。

## 当前定位

- 本目录承担背景层职责，重点说明需求、目标和方案语义。
- 本目录不再作为接口、表结构、状态机和实施流程的权威来源。
- 若本目录内容与 `docs/20-specs/` 冲突，以 `docs/20-specs/` 为准。

## 使用建议

1. 先读 `需求概述.md` 和 `open-world-ai-game-prd.md`，理解项目目标和玩法闭环
2. 再读 `功能设计.md`、`投票与社区需求文档.md`、`内容生成与审核需求文档.md`
3. 需要进入执行时，切换到 `docs/20-specs/README.md`
4. 需要查看接口时，切换到 `docs/30-api/README.md`

## 维护边界

- 允许保留需求背景、方案对比和里程碑语义
- 不继续重复维护实现细节、接口清单、数据库字段和状态机
- 如需表达“正式执行约束”，应改为引用 `docs/20-specs/` 而不是在本目录重复定义
