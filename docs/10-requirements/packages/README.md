# 专题需求包

> 文档状态：active
> 适用阶段：当前
> 维护要求：持续维护

## 目的

本目录用于保存基于现有规范重新组织而成的专题需求包，便于围绕单一主题快速阅读、沟通和交付。

## 适用范围

- 适用于把跨 `10-requirements/`、`20-specs/`、`30-api/` 的内容整理为单主题材料。
- 适用于 MVP 切片、专题交付包、演示包和阶段验收包。
- 不替代源规范，不承担新的权威层职责。

## 当前定位

- 本目录属于 `10-requirements/` 的子目录，定位为“背景与规范的专题化再包装输出”。
- 本目录中的文档必须回指源规范。
- 如与 `20-specs/` 或 `30-api/` 冲突，以源规范为准。
