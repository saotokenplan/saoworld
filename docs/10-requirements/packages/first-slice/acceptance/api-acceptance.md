# API 接口验收标准

> 版本：v1.0.0
> 创建时间：2026-07-04

> 说明：本文档用于从验收视角快速确认最小投票链路 API 是否“可用、可追踪、可联调”；正式响应格式、请求头、错误码与分页规则以 `docs/30-api/` 和 `docs/20-specs/backend-data-spec.md` 为准。

## 验收视图

| 主题 | 通过标准 |
|------|----------|
| 通用契约 | 响应结构统一、错误结构统一、请求追踪头与响应追踪头齐全 |
| 请求约束 | 玩家、写接口和运营写接口都满足对应请求头要求 |
| 玩家接口 | 能查当前投票、能提交投票、能查历史结果 |
| 运营接口 | 能创建并推进投票周期，且状态冲突时行为可预期 |
| 错误处理 | 参数错误、权限不足、状态冲突和资源不存在时返回稳定错误 |
| 分页与时间 | 列表接口支持分页，时间字段满足统一格式 |

## 推荐测试分组

### 通用接口

- 响应 envelope
- 错误结构
- 请求头校验
- 时间字段格式
- 分页行为

### 玩家接口

- `GET /api/v1/votes/current`
- `POST /api/v1/votes/submit`
- `GET /api/v1/votes/history`

### 运营接口

- 创建周期
- 排期周期
- 开放周期
- 关闭周期
- 结算周期

### 异常路径

- 缺少请求头
- 缺少权限
- 资源不存在
- 状态不允许
- 重复提交
