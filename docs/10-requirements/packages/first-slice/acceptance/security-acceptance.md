# 安全验收标准

> 版本：v1.0.0
> 创建时间：2026-07-04

> 说明：本文档用于快速确认最小投票链路在认证授权、输入输出保护、风控与审计方面的验收重点；正式安全规则、错误码和字段约束以源规范为准。

## 验收视图

| 安全主题 | 通过标准 |
|----------|----------|
| 认证授权 | 受保护接口必须完成 JWT 认证与 Scope 校验 |
| 数据安全 | 传输安全、敏感信息保护、输入校验和输出编码都满足要求 |
| 风控控制 | 幂等、频控、设备校验和行为识别能阻断异常投票 |
| 审计追踪 | 敏感操作都能形成完整审计链并支持查询 |
| 会话安全 | Token 生命周期和会话保护满足最小安全要求 |

## 推荐测试分组

### 认证与授权

- 无 Token、坏 Token、过期 Token
- Scope 不足
- 角色越权访问

### 输入输出与数据安全

- 参数格式与范围校验
- 敏感信息不回显
- 常见注入或脚本攻击防护

### 风控与幂等

- 重复提交
- 频率限制
- 设备异常
- 行为异常

### 审计与会话

- 敏感操作写审计
- `trace_id` 串联
- Token 过期与续期行为
