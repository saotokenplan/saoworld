# 投票功能验收标准

> 版本：v1.0.0
> 创建时间：2026-07-04

> 说明：本文档用于快速理解最小投票链路在产品视角下必须验收的能力；正式接口行为、错误码、状态机和性能门禁以 `docs/20-specs/`、`docs/30-api/` 与测试规范为准。

## 验收视图

| 验收主题 | 通过标准 |
|----------|----------|
| 周期管理 | 运营可以创建、推进、开放、关闭和结算投票周期，且状态推进可追溯 |
| 玩家投票 | 玩家能在开放周期内完成一次有效投票，重复提交不会重复计票 |
| 资格与风控 | 不满足资格、状态错误、候选无效或命中风险时，系统会阻断提交 |
| 结果展示 | 玩家可以查看当前周期与历史结果，结果能够关联后续落地内容 |
| 审计追踪 | 关键操作都能通过 `trace_id`、操作者和资源标识回溯 |
| 性能目标 | 投票提交、查询和结算满足最小可用性能门槛 |

## 推荐测试分组

### 运营路径

- 创建周期
- 推进周期状态
- 开放与关闭投票
- 结算并确认获胜方向

### 玩家路径

- 查询当前投票
- 提交有效投票
- 重复提交幂等
- 查询历史结果

### 约束路径

- 周期不存在或状态错误
- 候选项不存在或不属于当前周期
- 玩家资格不足
- 风控拦截

### 追踪与性能

- 审计日志完整性
- `trace_id` 串联
- 关键接口响应时间

## 安全验收

### 认证授权

**验收要求**：
- 未认证请求应返回 401 错误
- 权限不足请求应返回 403 错误
- Token 过期请求应返回 401 错误

**测试用例**：
- 未认证请求返回 401 错误 ✓
- 权限不足请求返回 403 错误 ✓
- Token 过期请求返回 401 错误 ✓

### 幂等性

**验收要求**：
- 同一 Idempotency-Key 重复提交只执行一次
- 幂等键全局唯一

**测试用例**：
- 同一 Idempotency-Key 重复提交只执行一次 ✓
- 不同 Idempotency-Key 可以正常提交 ✓

### 风控

**验收要求**：
- 设备指纹校验正常
- 频率限制正常

**测试用例**：
- 设备指纹校验测试 ✓
- 频率限制测试 ✓

## 状态机验收

### 投票周期状态迁移

**验收要求**：
- 状态迁移必须遵循合法路径
- 非法状态迁移应返回 409 错误

**测试用例**：
- draft → scheduled 合法 ✓
- scheduled → open 合法 ✓
- open → closed 合法 ✓
- closed → finalized 合法 ✓
- draft → open 非法 ✓
- open → draft 非法 ✓
- finalized → closed 非法 ✓

### 候选项状态迁移

**验收要求**：
- 状态迁移必须遵循合法路径
- 非法状态迁移应返回 409 错误

**测试用例**：
- active → selected 合法 ✓
- active → withdrawn 合法 ✓
- selected → active 非法 ✓

## 数据一致性验收

### 唯一性约束

**验收要求**：
- 同一章节下同时只能有一个 open 状态的投票周期
- 同一玩家在同一周期内只能投一票
- 幂等键全局唯一

**测试用例**：
- 同一章节下创建多个 open 状态投票周期应失败 ✓
- 同一玩家在同一周期内投多票应失败 ✓
- 使用相同幂等键提交多次应失败 ✓

### 外键约束

**验收要求**：
- 投票记录的 player_id 必须存在
- 投票记录的 candidate_id 必须存在
- 投票记录的 vote_cycle_id 必须存在

**测试用例**：
- 使用不存在的 player_id 投票应失败 ✓
- 使用不存在的 candidate_id 投票应失败 ✓
- 使用不存在的 vote_cycle_id 投票应失败 ✓
