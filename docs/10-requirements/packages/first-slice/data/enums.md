# 状态枚举定义

> 版本：v1.0.0
> 创建时间：2026-07-04

> 说明：本文档用于快速理解最小投票链路及其上下游常见状态集合；正式枚举值、CHECK 约束和状态迁移路径以 `docs/20-specs/backend-data-spec.md` 为准。

## 阅读方式

- 本文档不再重复维护完整枚举字典、审计枚举和 SQL 约束。
- 这里只保留“哪些领域有状态”“这些状态在业务上分别代表什么”。
- 若需要确定精确枚举值、迁移路径或数据库约束，请直接查源规范。

## 业务上最常用的状态组

| 领域 | 读者需要理解什么 |
|------|------------------|
| 投票周期 | 周期会经历创建、排期、开放、关闭和结算等阶段 |
| 投票候选项 | 候选项会处于可投、撤回或当选等状态 |
| 区域与任务 | 区域和任务都有自己的可见性与进度状态 |
| 审核与风险 | 审核结果和风险等级决定内容是否进入下一步 |
| 发布与回滚 | 内容包存在灰度、上线、归档与回滚等状态 |
| 生成任务与生成对象 | 生成流程需要区分处理中、成功、失败和待审核等阶段 |
