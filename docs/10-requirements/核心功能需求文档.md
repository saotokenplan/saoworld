# 核心功能需求文档

> 文档状态：active
> 适用阶段：需求实现
> 维护要求：持续维护
> 更新频率：每Sprint更新

## 文档定位

本文档以用户故事格式整理游戏核心功能需求，用于说明玩家体验目标、核心场景和验收意图，帮助研发理解“要做出什么体验”。具体交互参数、接口契约、数据结构和工程实现细节，应回到 `docs/20-specs/`、`docs/30-api/` 与对应服务/客户端规范中维护。

## 一、玩家探索系统

### 1.1 玩家移动

| 项目 | 内容 |
|------|------|
| 角色 | 探索型玩家 |
| 目标 | 在世界中自由移动，探索不同区域 |
| 优先级 | P0 |

**用户故事**：
- 作为一名探索型玩家，我希望使用键盘/手柄控制角色在区域内移动，以便探索世界中的地标和资源
- 作为一名探索型玩家，我希望靠近地标时触发场景切换或交互提示，以便进入新区域或触发事件
- 作为一名探索型玩家，我希望移动时有平滑的动画效果，以便获得良好的视觉体验

**验收标准**：
- 玩家可使用 WASD/方向键/手柄摇杆控制移动
- 移动时角色播放行走/跑步动画
- 靠近地标时显示交互提示（如"按E进入"）
- 进入地标后触发场景切换，加载新区域

**相关需求**：S1-01

---

### 1.2 世界地图

| 项目 | 内容 |
|------|------|
| 角色 | 探索型玩家 |
| 目标 | 查看世界地图，了解区域分布和解锁状态 |
| 优先级 | P0 |

**用户故事**：
- 作为一名探索型玩家，我希望打开世界地图查看所有区域，以便了解世界布局
- 作为一名探索型玩家，我希望地图上显示已解锁和未解锁区域，以便规划探索路线
- 作为一名探索型玩家，我希望点击地图上的区域快速移动或查看详情，以便高效导航

**验收标准**：
- 按M键打开世界地图
- 地图显示区域层级（核心大陆、扩展区域、异变区域）
- 未解锁区域显示为灰色/迷雾状态
- 已解锁区域显示详细信息（名称、危险等级、已发现地标）
- 点击区域可查看区域详情或快速旅行

**相关需求**：S1-02

---

| 项目 | 内容 |
|------|------|
| 角色 | 探索型玩家 |
| 目标 | 发现并探索地标，获取奖励和线索 |
| 优先级 | P0 |

**用户故事**：
- 作为一名探索型玩家，我希望在区域内发现地标，以便获取探索奖励
- 作为一名探索型玩家，我希望探索地标时触发事件或获得资源，以便增强角色

- 已探索地标在地图上标记为已发现
- 探索进度在个人中心显示

**相关需求**：S1-02

|------|------|
| 角色 | 探索型玩家 |
| 目标 | 与NPC对话，获取任务和剧情信息 |
| 优先级 | P0 |

**用户故事**：
- 作为一名探索型玩家，我希望靠近NPC时触发对话，以便了解剧情和获取任务
- 作为一名探索型玩家，我希望对话界面显示NPC头像和对话文本，以便获得沉浸式体验
- 作为一名探索型玩家，我希望对话结束后NPC返回正常行为，以便继续探索

**验收标准**：
- 靠近NPC时显示"按E对话"提示

- 对话文本逐字显示，支持跳过
- 对话结束后NPC恢复正常状态

**相关需求**：S1-03

---

### 2.2 对话分支

| 项目 | 内容 |
|------|------|
| 角色 | 探索型玩家 |
| 目标 | 通过对话分支影响剧情走向和NPC态度 |
| 优先级 | P1 |

**用户故事**：
- 作为一名探索型玩家，我希望对话中有多个选项，以便表达不同态度
- 作为一名探索型玩家，我希望不同对话选择影响NPC好感度或任务走向，以便获得不同奖励
- 作为一名探索型玩家，我希望对话选项根据玩家状态动态变化，以便获得个性化体验

**验收标准**：
- 对话中显示2-4个选项
- 选择不同选项触发不同回复
- 对话选择影响阵营声望或任务分支
- 玩家状态（等级、声望、物品）影响可用选项

**相关需求**：S1-03

| 目标 | 与敌人触发战斗 |
| 优先级 | P0 |

**用户故事**：
- 作为一名探索型玩家，我希望在探索时遇到敌人并触发战斗，以便获得挑战和奖励
- 作为一名探索型玩家，我希望战斗界面清晰显示双方状态，以便做出决策

| 项目 | 内容 |
|------|------|
| 角色 | 探索型玩家 |
| 目标 | 通过获得经验提升等级 |
| 优先级 | P1 |

**用户故事**：
- 作为一名探索型玩家，我希望完成任务和战斗获得经验，以便提升等级
- 作为一名探索型玩家，我希望等级提升后获得属性增强，以便变得更强
- 作为一名探索型玩家，我希望等级提升后解锁新内容，以便获得新体验
