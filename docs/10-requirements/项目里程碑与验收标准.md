# 项目里程碑与验收标准

> 文档状态：active
> 适用阶段：项目管理
> 维护要求：持续维护
> 更新频率：每里程碑完成后更新

## 文档定位

本文档定义项目的里程碑节点和验收标准，确保项目按计划推进，每个阶段的交付物符合质量要求。

本文档用于维护项目级里程碑、阶段目标和管理视角的验收背景，不作为产品规则、工程门禁、接口契约或数据库约束的权威来源。若具体验收项与 `docs/20-specs/` 下执行规范冲突，以后者为准。

## 三、Sprint验收标准

### 3.1 Sprint验收流程

1. **需求验收**：产品经理验证需求是否按计划完成
2. **代码验收**：技术负责人验证代码质量和规范
3. **测试验收**：QA验证测试覆盖率和Bug修复
4. **文档验收**：文档负责人验证文档更新完整
5. **部署验收**：运维验证部署流程和环境配置

### 3.2 Sprint验收指标

| 指标 | 标准 |
|------|------|
| 需求完成率 | ≥ 90% |
| 测试通过率 | ≥ 95% |
| 代码审查通过 | 100% |
| 文档更新完整 | 100% |
| 部署成功率 | 100% |

### 3.3 Sprint验收模板

```markdown
# Sprint N 验收报告
```
