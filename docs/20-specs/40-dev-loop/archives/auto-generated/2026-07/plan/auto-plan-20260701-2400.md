### 步骤 3：补充 Repository 方法

- `VoteRepository.create_vote_cycle()`：创建投票周期（含候选）
- `VoteRepository.get_cycle_by_id()`：按 ID 获取周期
- `VoteRepository.transition_cycle_status()`：状态迁移
- `VoteRepository.get_open_cycle_for_chapter()`：检查章节是否有开放周期
- `VoteRepository.tally_votes()`：计票逻辑
- `VoteRepository.withdraw_candidate()`：撤回候选项
- `VoteRepository.get_all_candidates_for_cycle()`：获取周期所有候选项（含非 active）

### 步骤 4：实现运营 API 路由

- `POST /api/v1/ops/vote-cycles`：创建投票周期
- `POST /api/v1/ops/vote-cycles/{vote_cycle_id}/open`：开放投票
- `POST /api/v1/ops/vote-cycles/{vote_cycle_id}/close`：关闭投票（触发计票）
- `POST /api/v1/ops/vote-cycles/{vote_cycle_id}/finalize`：确认结果
- 所有运营接口需 `Idempotency-Key` 和 `X-Trace-Id` 请求头
