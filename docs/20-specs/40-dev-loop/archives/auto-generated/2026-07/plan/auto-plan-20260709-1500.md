- 新增 `player_metrics_daily` 表（玩家每日指标聚合表）
- 新增 `region_metrics_daily` 表（区域每日指标聚合表）
- 新增 `quest_metrics_daily` 表（任务每日指标聚合表）
- 新增 `vote_metrics_daily` 表（投票每日指标聚合表）
- 创建 Alembic 迁移脚本
- 实现对应的 Repository 层

### 步骤 2：实现数据清洗与统计分析任务（workers）
- 在 workers 中新增数据分析任务模块
- 实现数据清洗任务（去重、过滤、标准化）
- 实现每日指标聚合任务（玩家维度、区域维度、任务维度、投票维度）
- 实现趋势分析任务（7天/30天趋势计算）
- 集成到 Celery Beat 定时调度

### 步骤 3：实现分析查询 API（ops-service）
- 在 ops-service 中新增 analytics 路由模块

- 实现 `GET /api/v1/analytics/trends` 趋势分析查询
- 实现 `GET /api/v1/analytics/reports` 分析报告列表
- 统一响应 envelope 格式
