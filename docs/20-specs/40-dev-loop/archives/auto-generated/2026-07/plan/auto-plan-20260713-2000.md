## 具体执行步骤

### 步骤 1：生成 Alembic 迁移脚本

为 vote-service 新增讨论区相关表的迁移脚本：
- `vote_discussions` 表（讨论主帖）
- `vote_discussion_replies` 表（讨论回复）
- `vote_discussion_likes` 表（点赞记录）

参考现有迁移脚本格式，确保：
- 主键使用 UUID
- 审计字段（created_at）
- CHECK 约束（status 合法值、content 长度）
- 外键约束（ON DELETE RESTRICT / CASCADE）
- 索引配置

### 步骤 2：客户端 VoteManager 扩展讨论区方法

在 `game/scripts/autoload/VoteManager.gd` 中新增：
- `fetch_discussions(vote_cycle_id: String, sort_by: String = "time", limit: int = 20, offset: int = 0) -> void` - 获取讨论列表
- `create_discussion(vote_cycle_id: String, content: String) -> bool` - 发布讨论
- `like_discussion(discussion_id: String) -> bool` - 点赞讨论
- `unlike_discussion(discussion_id: String) -> bool` - 取消点赞
- `fetch_replies(discussion_id: String, limit: int = 20, offset: int = 0) -> void` - 获取回复列表
- `create_reply(discussion_id: String, content: String) -> bool` - 发布回复
- `like_reply(reply_id: String) -> bool` - 点赞回复
- `unlike_reply(reply_id: String) -> bool` - 取消回复点赞

新增信号：
- `discussions_loaded(discussions: Array, meta: Dictionary)`
- `discussion_created(discussion: Dictionary)`
- `replies_loaded(discussion_id: String, replies: Array, meta: Dictionary)`
- `reply_created(reply: Dictionary)`
- `discussion_like_changed(discussion_id: String, liked: bool, like_count: int)`

新增变量：
- `discussions: Array[Dictionary] = []`
- `current_discussion_id: String = ""`
- `replies: Array[Dictionary] = []`

### 步骤 3：讨论区 UI 面板实现

创建讨论区面板场景和脚本：
- `game/scenes/ui/voting/VoteDiscussionPanel.tscn` - 讨论区面板场景
- `game/scripts/ui/vote_discussion_panel.gd` - 讨论区面板脚本

功能要求：
- 讨论列表显示（支持按热度/时间排序切换）
- 每条讨论显示：玩家ID、内容、点赞数、回复数、发布时间
- 发布讨论输入框和按钮
- 点赞按钮（点赞/取消点赞状态切换，图标变化）
- 点击讨论展开回复列表
- 回复列表显示
- 回复发布输入框和按钮
- 加载状态提示
- 错误提示

### 步骤 4：投票界面集成讨论区入口
