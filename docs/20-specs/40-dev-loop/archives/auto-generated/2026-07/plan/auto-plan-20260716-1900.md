## 任务目标与背景

### 目标
完成 M2-02 公会任务功能的客户端部分，包括 GuildManager 扩展和 GuildQuestPanel 场景，实现玩家在客户端查看、接取和完成公会任务的完整能力。

### 背景
M2-02 公会任务功能的后端部分已在 auto-20260716-1800 中完成，包括 `guild_quests` 和 `guild_quest_progress` 两张核心表、仓储层、6 个 API 端点、Schema 和错误码定义。客户端部分是该功能的重要组成部分，缺少客户端实现会导致玩家无法在游戏中使用公会任务功能。

## 具体执行步骤

### 步骤 1：扩展 GuildManager 添加公会任务相关方法
- 新增公会任务 API 调用方法（获取任务列表、获取任务详情、获取任务进度、更新任务进度、领取奖励）
- 新增相关信号（guild_quests_loaded、guild_quest_progress_updated、guild_quest_reward_claimed、guild_quest_error）
- 新增数据状态管理（任务列表缓存、进度缓存）

### 步骤 2：创建 GuildQuestPanel 公会任务面板场景
- 创建场景文件（GuildQuestPanel.tscn）
- 实现界面布局（任务列表、任务详情、进度条、领取奖励按钮）
- 实现交互逻辑（任务选择、进度显示、奖励领取）

### 步骤 3：集成到公会界面
- 在 GuildPanel 中添加公会任务标签页
- 关联 GuildManager 信号与 GuildQuestPanel

### 步骤 4：编写客户端 GUT 测试
- 为 GuildManager 新增公会任务相关测试用例
- 为 GuildQuestPanel 新增测试用例
