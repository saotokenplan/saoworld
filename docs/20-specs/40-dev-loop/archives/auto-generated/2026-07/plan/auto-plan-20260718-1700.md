## 任务目标

为 M3 里程碑新增跨服匹配系统完整后端能力，覆盖：

1. **匹配队列管理**：玩家加入/退出匹配队列，按段位和等级匹配
2. **对战房间管理**：匹配成功后创建对战房间，管理对战生命周期
3. **对战记录系统**：记录对战结果，统计胜率和段位变化
4. **段位系统**：段位等级划分、段位积分计算、赛季重置
5. **匹配 API**：玩家侧和运营侧完整 API 端点
6. **测试覆盖**：为新增功能补充单元测试

## 核心设计

### 匹配机制

- **匹配模式**：1v1 单人匹配（首期）
- **匹配因子**：段位等级 ±2、玩家等级 ±10
- **匹配超时**：最长 120 秒，超时后扩大匹配范围
- **段位系统**：青铜 → 白银 → 黄金 → 铂金 → 钻石 → 大师 → 王者，每段 5 个小段

### 数据模型

- `match_queues`：匹配队列（玩家加入队列的记录）
- `match_rooms`：对战房间（匹配成功后的对局）
- `match_results`：对战结果记录
- `player_ratings`：玩家段位与积分
- `match_seasons`：赛季配置

### API 端点

**玩家侧（8个）：**
- `GET /match/rating` - 查询我的段位和积分
- `POST /match/queue/join` - 加入匹配队列
- `POST /match/queue/leave` - 退出匹配队列
- `GET /match/queue/status` - 查询匹配状态
- `GET /match/rooms/{room_id}` - 查询对战房间详情
- `POST /match/rooms/{room_id}/ready` - 准备就绪
- `POST /match/rooms/{room_id}/result` - 提交对战结果
- `GET /match/history` - 对战历史记录

**运营侧（5个）：**
- `GET /ops/match/queues` - 匹配队列列表
- `GET /ops/match/rooms` - 对战房间列表
- `GET /ops/match/results` - 对战结果列表
- `GET /ops/match/seasons` - 赛季列表
- `POST /ops/match/seasons` - 创建赛季
