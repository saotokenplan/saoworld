# 公告模板

> 文档状态：active
> 适用版本：公测 v0.1.0

## 概述

本文档提供运营公告的标准模板和发布流程，确保公告格式统一、信息清晰。

## 公告类型

| 类型 | 优先级 | 说明 |
|------|--------|------|
| 紧急公告 | 高 | 服务器维护、紧急修复、安全公告 |
| 常规公告 | 中 | 更新说明、活动预告、投票周期通知 |
| 社区公告 | 低 | 社区活动、玩家故事、官方动态 |

## 标准格式

### 标题格式

```
【公告类型】公告标题
```

示例：
- 【紧急】服务器临时维护通知
- 【更新】v0.1.1 版本更新说明
- 【活动】双倍经验周开启

### 正文结构

1. **开头**：简要说明公告目的
2. **详情**：具体内容描述
3. **时间**：相关时间信息（开始/结束时间）
4. **影响**：对玩家的影响说明
5. **注意事项**：需要玩家注意的事项

## 模板

### 紧急公告模板

```

YYYY-MM-DD HH:MM - HH:MM（服务器时间）

- [受影响功能1]
- [受影响功能2]

YYYY-MM-DD
```

## 发布流程

### 草稿阶段

1. 确定公告类型和主题
2. 撰写公告内容（使用对应模板）
3. 内部审核（检查信息准确性、格式规范性）

### 发布阶段

1. 在游戏内公告系统发布
2. 在官方社区同步发布
3. 如需紧急公告，通过推送通知同步

### 后续跟进

1. 监控玩家反馈
2. 如有需要，发布补充公告
3. 活动结束后发布结果公告

## 注意事项

- 公告内容必须真实准确，不得发布虚假信息
- 公告语言应简洁明了，避免专业术语
- 时间格式统一使用 YYYY-MM-DD HH:MM（服务器时间）
- 紧急公告应在确认后尽快发布
- 常规公告应提前至少24小时发布预告
