# 新手引导

> 文档状态：active
> 适用版本：公测 v0.1.0

## 欢迎来到「命运抉择」世界

这是一个由玩家投票驱动、AI持续生成内容的大型开放式在线游戏。你的每一次投票都将影响世界的走向，每一次探索都可能发现新的内容。

## 快速开始

### 1. 创建角色

进入游戏后，你需要创建自己的角色：

- **角色名称**：选择一个独特的名字
- **初始阵营**：选择你所属的势力（铁卫联盟、自由领地、暗影面纱、丰收商会）
- **角色外观**：自定义你的角色形象

### 2. 基本操作

- **移动**：使用 WASD 或方向键移动角色
- **交互**：靠近 NPC 或可交互对象后按 E 键进行交互
- **打开菜单**：按 ESC 键打开主菜单
- **背包**：按 I 键打开背包
- **任务**：按 Q 键打开任务面板
- **地图**：按 M 键打开世界地图

### 3. 核心玩法

游戏的核心玩法闭环：**探索 → 参与 → 投票 → 世界更新 → 再探索**

#### 探索世界

- 从世界地图选择区域进行探索
- 与 NPC 对话接取任务
- 探索区域中的关键地点
- 与敌人战斗获得经验和奖励

#### 参与活动

- 完成主线和支线任务
- 参与公会活动
- 与其他玩家社交（好友、私聊、公会）
- 参与运营事件（双倍经验、登录礼包等）

#### 投票决策

- 定期开放的投票周期让玩家决定世界走向
- 投票周期开放时，在主菜单点击「投票」进入投票界面
- 查看各候选项的详细信息和影响范围
- 投出你的一票，影响游戏世界的未来

#### 世界更新

- 投票结算后，获胜选项将驱动 AI 生成新内容
- 新内容通过内容包形式发布
- 玩家可通过内容更新界面查看新内容
- 新内容可能包含新区域、新任务、新 NPC

## 快速升级指南

### 初期（1-10级）

1. **完成主线任务**：主线任务提供大量经验，是快速升级的首选
2. **探索核心区域**：铁卫城周边是新手友好区域，适合初期探索
3. **接取支线任务**：支线任务提供额外经验和奖励
4. **参与运营事件**：公测期间可能有双倍经验等活动

### 中期（10-30级）

1. **解锁新区域**：提升声望解锁幽光森林、南部绿洲等区域
2. **挑战 Boss**：击败区域 Boss 获得高级装备和大量经验
3. **完成副本**：参与副本挑战获得团队经验和奖励
4. **公会活动**：加入公会参与公会活动

### 后期（30级以上）

1. **参与投票**：更高等级解锁更多投票权重
2. **收集成就**：完成成就获得奖励和称号
3. **挑战高难度内容**：探索不稳定区域，挑战强力敌人
4. **社交互动**：与其他玩家组队、交易、交流

## 重要提示

- **定期保存**：游戏支持自动保存，但建议手动保存以防意外
- **关注公告**：游戏内公告会通知投票周期、运营活动等重要信息
- **提供反馈**：使用游戏内反馈功能报告问题或提出建议
- **加入社区**：关注官方社区获取最新资讯和攻略
