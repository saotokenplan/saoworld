# 内容生成详细规范

## 目标

本规范定义 AI 内容生成的输入、输出、模板约束、审核维度和上线生命周期。原则是“结构化约束优先，生成润色其次”，避免把一整批世界内容直接交给自由文本生成。

## 生成对象范围

### 当前允许生成

- NPC 定义
- 聚落定义
- 支线任务
- 局部世界事件
- 遭遇配置描述
- 区域叙事文本

### 当前禁止自由生成

- 主线终局节点
- 核心经济参数
- 高价值奖励上限
- 战斗底层规则
- 世界观根设定

## 世界骨架约束

AI 生成前必须载入世界骨架快照，至少包含：

- `world_version`
- 当前章节与阶段
- 阵营定义与敌对关系
- 区域目录
- 角色保留名单
- 禁用主题
- 奖励与强度上限

没有骨架快照的生成请求必须直接拒绝。

## 生成输入规范

### 输入来源

生成输入只能来自以下五类信息：

- 投票结果
- 当前章节与区域上下文
- 玩家行为摘要
- 内容模板
- 规则边界

### 标准输入结构

```json
{
  "request_id": "gen_20260625_001",
  "chapter_id": "chapter_02",
  "region_id": "region_wasteland_01",
  "vote_result": {
    "theme": "荒原废墟",
    "faction_conflict": "机械教团_vs_流亡者",
    "npc_fate": "流亡者首领幸存",
    "event_direction": "资源争夺升级"
  },
  "player_summary": {
    "preferred_activity": ["探索", "支线", "阵营任务"],
    "avg_power_band": "mid",
    "popular_enemy_type": ["机械体", "掠夺者"]
  },
  "constraints": {
    "danger_level": 4,
    "reward_tier_cap": "mid",
    "allowed_tags": ["废墟", "求生", "压抑"],
    "forbidden_tags": ["现代政治映射", "极端暴力", "现实宗教影射"]
  },
  "template_id": "wasteland_branch_pack_v2"
}
```

### 输入校验规则

- 必须包含 `chapter_id`、`region_id`、`constraints`
- `danger_level` 只能取 `1-5`
- `reward_tier_cap` 必须落在当前章节允许区间
- `forbidden_tags` 不能为空
- `template_id` 必须可追溯到模板仓库版本

## 生成输出规范

### NPC 输出

每个 NPC 必须包含：

- `npc_id`
- 名称
- 身份
- 阵营
- 职业
- 个性标签 `3-5` 个
- 语气标签 `1-3` 个
- 常驻区域
- 关系引用
- 出现条件

### 任务输出

每个任务必须包含：

- `quest_id`
- 任务类型
- 触发条件
- 目标列表
- 地点
- 敌人或交互对象
- 推荐强度
- 奖励表
- 失败处理
- 剧情影响标签

### 聚落输出

每个聚落必须包含：

- `settlement_id`
- 聚落类型
- 外观风格标签
- 居民构成
- 主资源
- 管理势力
- 主要冲突
- 交互点列表

### 事件输出

每个事件必须包含：

- `event_id`
- 触发时机
- 影响范围
- 参与条件
- 成功条件
- 结束条件
- 对区域状态的影响

## 模板机制规范

### 模板层级

- `世界模板`
  - 约束章节、阵营、区域类型和禁用主题
- `区域模板`
  - 约束地貌、资源、敌人池和聚落风格
- `任务模板`
  - 约束任务骨架、目标类型和奖励槽位
- `文案模板`
  - 约束语气、词汇和叙事风格

### 模板使用规则

- 所有生成都必须先匹配模板，再做填充和润色
- 模板版本必须写入最终审计记录
- 模板升级后不能自动覆盖已上线内容，必须走内容包新版本

## 质量评分规范

每个生成对象在进入审核前都要先得到质量分。建议维度如下：

| 维度 | 说明 | 分值范围 |
|------|------|----------|
| 结构完整度 | 必填字段是否齐全 | 0-100 |
| 世界一致性 | 是否与阵营、区域、章节冲突 | 0-100 |
| 数值合理性 | 强度、奖励、资源是否在边界内 | 0-100 |
| 文本质量 | 是否通顺、是否过度重复 | 0-100 |
| 差异性 | 与历史内容重复度是否过高 | 0-100 |

总分低于 `75` 的内容不得进入投放打包。

## 审核规则规范

### 世界一致性审核

- 阵营关系不能与骨架快照冲突
- NPC 身份不能越过章节认知边界
- 聚落资源必须与地貌和势力匹配
- 事件影响不能直接改写主线终局

### 数值审核

- 奖励不得突破章节上限
- 敌人强度不得超出区域允许区间
- 重复支线累计收益不得形成刷取漏洞
- 资源刷新必须落在服务器配置区间

### 内容安全审核

- 命中敏感词直接驳回
- 涉及高风险主题进入人工复核
- 不符合目标年龄层表达直接驳回

### 重复度审核

- 同章节 NPC 设定相似度阈值不高于 `0.8`
- 同区域支线骨架复用比例不高于 `0.6`
- 文案段落重复率不高于 `0.3`

## 内容生命周期

每个内容对象都要遵循以下状态：

`draft -> validated -> reviewed -> packaged -> gray -> live -> archived`

### 状态说明

- `draft`：模型刚生成
- `validated`：通过结构化校验
- `reviewed`：通过自动审核和人工复核
- `packaged`：已打入内容包
- `gray`：灰度上线
- `live`：正式生效
- `archived`：下线归档

## 回滚规范

- 回滚最小单位为 `content_package_id`
- 已上线内容必须保留上一个稳定版本
- 回滚后必须写入原因、影响范围和对应日志链接
- 同类内容连续回滚超过 `2` 次时，暂停对应模板继续使用

## 人工复核触发条件

以下情况必须触发人工复核：

- 质量总分处于 `75-85`
- 命中高风险主题词
- 新模板首次上线
- 奖励或剧情影响接近边界阈值
- 生成对象关联核心阵营或关键角色
