## 任务目标与背景

### 为什么要做这件事

Sprint 1 P0 项已全部完成，项目进入 Sprint 2 AI 生成接入阶段。

当前 generation-service 已具备：
- LLM 服务适配器（支持 OpenAI API 和 Mock）- S2-01 完成
- 内容生成器（NPC/任务/区域描述生成）- S2-01 完成
- 模板管理模块（TemplateManager，支持模板加载、匹配、版本管理）- auto-20260710-0900 完成
- 质量评分模块（QualityScorer，质量阈值 0.75）- auto-20260710-0900 完成
- 内容生成 Celery 异步任务（process_generation_request）- auto-20260710-0900 完成

但缺少 **完整的 NPC 生成模板**：
- 当前模板仅为示例，字段不完整（缺少背景故事、性格特征、对话树、任务关联等）
- 生成的 NPC 数据无法直接导入 world-service 的 NPC 系统
- NPC 字段完整度未达到验收标准（>95%）

根据需求迭代计划 Sprint 2 S2-02「NPC生成模板」为 P0 优先级，验收标准：「生成的NPC字段完整度>95%，符合世界观」。

### 目标

实现完整的 NPC 生成模板体系，包括：
1. 完善 NPC 生成模板（包含全部必需字段）
2. 实现 NPC 模板渲染逻辑（基于世界骨架和投票结果）
3. 实现 NPC 生成后的数据转换（适配 world-service NPC 数据结构）
4. 集成质量评分（确保生成质量达标）
5. 完整测试覆盖

## 具体执行步骤

### 步骤 1：设计 NPC 生成模板结构

- 分析 world-service NPC 数据模型（npc_list.json、npcs 数据库表）
- 确定 NPC 生成模板必需字段：
  - 基础信息：name、title、gender、age、race、faction_id、region_id、status
  - 外观描述：appearance、avatar_key
  - 性格特征：personality、traits、voice
  - 背景故事：backstory、motivation、relationship_map
  - 对话配置：dialog_style、dialog_nodes（问候、任务触发、闲聊）
  - 任务关联：quests_given、quests_related
  - 经济信息：shop_items、services_offered
  - 位置信息：location_x、location_y、interaction_radius

### 步骤 2：创建 NPC 生成模板文件

- 创建 `services/generation/templates/npc/npc_base.jinja2`：基础 NPC 模板
- 创建 `services/generation/templates/npc/npc_blacksmith.jinja2`：铁匠 NPC 模板
- 创建 `services/generation/templates/npc/npc_merchant.jinja2`：商人 NPC 模板
- 创建 `services/generation/templates/npc/npc_guard.jinja2`：守卫 NPC 模板
- 创建 `services/generation/templates/npc/npc_healer.jinja2`：治疗师 NPC 模板
- 创建 `services/generation/templates/npc/npc_quest_giver.jinja2`：任务发布者模板
- 每个模板包含完整字段定义和 Prompt 指令

### 步骤 3：实现 NPC 模板渲染逻辑

- 更新 `app/core/template_manager.py`：
  - 添加 NPC 模板匹配策略（基于 faction、region、role）
  - 添加模板变量注入（world_skeleton、vote_result、region_context）
- 更新 `app/core/content_generator.py`：
  - 优化 `generate_npc_description()` 方法
  - 添加 NPC 专用生成参数构建
  - 添加生成结果结构化解析（JSON 格式输出）

### 步骤 4：实现 NPC 数据转换适配器

- 创建 `app/core/npc_data_adapter.py`：
  - 实现生成结果到 world-service NPC 数据结构的转换
  - 验证字段完整性（确保>95%字段已填充）
  - 处理缺失字段的默认值填充
  - 验证数据格式（UUID、枚举值等）

### 步骤 5：集成质量评分与内容审核

- 更新 `app/core/quality_scorer.py`：
  - 添加 NPC 专用评分指标（字段完整性、世界观一致性、对话质量）
  - 设置 NPC 质量评分权重
- 更新 `app/tasks/content_generation.py`：
  - 添加 NPC 生成后的质量评分步骤
  - 添加质量不达标时的重试逻辑

### 步骤 6：测试编写

- 创建 `tests/test_npc_template.py`：NPC 模板加载与渲染测试
- 创建 `tests/test_npc_data_adapter.py`：NPC 数据转换测试
- 创建 `tests/test_npc_generation_integration.py`：NPC 生成端到端测试
- 使用 MockLLMAdapter 进行单元测试
