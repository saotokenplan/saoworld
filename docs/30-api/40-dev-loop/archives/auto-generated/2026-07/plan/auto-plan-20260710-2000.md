## 具体执行步骤

### 步骤 1: 新增 PlayerInventory 数据模型

在 `services/player/app/domain/models.py` 中添加 `PlayerInventory` 表：
- `inventory_id`：UUID 主键
- `player_id`：外键指向 players 表
- `item_key`：物品标识（如 `item_health_potion_01`）
- `item_type`：物品类型（consumable/equipment/material/quest_item）
- `quantity`：数量
- `metadata_jsonb`：物品元数据（属性、描述等）
- 审计字段：created_at, updated_at
- CHECK 约束：item_type 合法值、quantity > 0
- 索引：player_id + item_key 唯一索引

### 步骤 2: 创建 Alembic 迁移脚本

为 `player_inventories` 表创建 Alembic 迁移脚本。

### 步骤 3: 新增 InventoryRepository 仓储层

在 `services/player/app/repositories/inventory_repo.py` 中实现：
- `get_inventory(player_id, limit, offset)`：查询玩家背包
- `get_item(player_id, item_key)`：查询单个物品
- `add_item(player_id, item_key, item_type, quantity, metadata)`：添加物品（存在则叠加数量）
- `remove_item(player_id, item_key, quantity)`：移除物品（数量不足则报错）
- `use_item(player_id, item_key, quantity)`：使用消耗品

### 步骤 4: 新增 Pydantic Schemas

在 `services/player/app/schemas/player.py` 中添加：
- `InventoryItemResponse`：背包物品响应
- `AddItemRequest`：添加物品请求
- `RemoveItemRequest`：移除物品请求
- `UseItemRequest`：使用物品请求

### 步骤 5: 新增 API 路由

在 `services/player/app/api/routes.py` 中添加：
- `GET /api/v1/player/inventory`：查询背包（玩家接口）
- `POST /api/v1/player/inventory/use`：使用物品（玩家接口）
- `POST /api/v1/ops/players/{player_id}/inventory`：添加物品（运营接口）
- `DELETE /api/v1/ops/players/{player_id}/inventory/{item_key}`：移除物品（运营接口）

### 步骤 6: 新增错误码

在 `services/player/app/core/errors.py` 中添加：
- `ITEM_NOT_FOUND`：物品不存在
- `INSUFFICIENT_QUANTITY`：物品数量不足
- `INVALID_ITEM_TYPE`：无效的物品类型

### 步骤 7: 新增 Prometheus 业务指标

在 `services/player/app/core/metrics.py` 中添加：
- `inventory_operations_total`：背包操作计数

### 步骤 8: 新增审计动作常量

在 `services/player/app/repositories/audit_repo.py` 中添加：
- `ACTION_INVENTORY_ADD`：添加物品
- `ACTION_INVENTORY_REMOVE`：移除物品
- `ACTION_INVENTORY_USE`：使用物品
- `RESOURCE_INVENTORY`：资源类型

### 步骤 9: 新增后端测试用例

在 `services/player/tests/` 中添加测试：

- 添加物品测试（新增+叠加）
- 使用物品测试

### 步骤 10: 客户端 InventoryManager 自动加载单例
