## 一、任务目标与背景

### 1.1 任务目标

实现 Sprint 1 P1 项 S1-08「声望解锁系统」，完成以下核心能力：
- 声望解锁条件数据结构定义（区域、任务、NPC 三级解锁）
- 声望解锁判断逻辑（后端 + 客户端）
- 区域声望解锁（声望达到阈值自动解锁新区域）
- 任务声望可见性（声望不足时任务不显示）
- NPC 声望交互限制（声望不足时 NPC 对话受限）

### 1.2 背景说明

S1-07「声望系统基础」已完成，玩家可以通过完成任务获得声望，但声望目前只有数值展示，没有实际的玩法影响。本轮实现声望解锁系统，让声望真正影响游戏内容：
- 声望达到阈值 → 解锁新区域、新任务、新对话选项
- 形成「探索→任务→声望→更多内容」的完整正向循环
- 为后续阵营声望、NPC 好感度等系统奠定基础

### 1.3 现有基础

**后端（player-service）：**
- `PlayerRegion` 表已有 `reputation` int 字段
- `PlayerRegionRepository` 已有 `add_reputation`、`get_region_reputation`、`update_region_reputation` 方法
- `ReputationLevel` 枚举和 `get_reputation_level()` 工具函数已定义
- 6 个声望等级：敌对/中立/友好/尊敬/崇敬/崇拜，阈值 -3000/0/3000/9000/21000/42000
- 任务完成时自动增加对应区域声望

**后端（world-service）：**
- `Region` 表已有 `unlock_condition` JSONB 字段
- `NPC` 和 `QuestDefinition` 表已存在

**客户端：**
- `PlayerManager` 已有声望管理方法
- `ReputationPanel` 场景已实现
