## 具体执行步骤

### 步骤 1：扩展 `game/tests/test_vote_manager.gd`

为 VoteManager 的 5 个落地信息方法补充测试用例：

- `is_vote_landed(vote_item)`
  - 无 `content_package` 字段时返回 `false`
  - `content_package` 为空字典时返回 `false`
  - `content_package` 非空时返回 `true`
- `get_vote_history_with_landing()`
  - 空历史时返回空数组
  - 包含落地与未落地混合项时，每项均带 `is_landed` 标记且原始字段保留
- `get_content_package_for_vote(cycle_id)`
  - 命中 `vote_cycle_id` 时返回对应 `content_package`
  - 命中 `cycle_id` 别名时返回对应 `content_package`
  - 未命中时返回空字典
- `get_landed_at(vote_item)`
  - 有 `released_at` 时返回该值
  - 无 `content_package` 时返回空字符串
- `get_affected_regions(vote_item)`
  - `payload.regions` 为字典数组时返回 `name`/`region_id` 列表
  - `payload.regions` 为字符串数组时返回字符串列表
  - 无 `payload` 或 `regions` 时返回空数组

每个测试结束后调用 `vm.reset()` 恢复状态，遵循现有测试文件的 AAA 模式与命名风格。

### 步骤 2：创建 `game/tests/test_content_package_detail.gd`

- `closed` 信号在关闭按钮与背景点击时正确发射

测试通过 `partial_double` 或直接实例化场景脚本方式运行，确保不依赖完整场景树加载。
