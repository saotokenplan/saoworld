## 任务背景

项目当前处于 M3 里程碑推进阶段。根据 `docs/00-governance/project-status.md` 的"后续迭代方向"，中期任务包含「经济系统运营监控指标」，目前尚未完成。

经济系统（钱包/交易/拍卖行）已在 M2-03 完成后端实现（player-service 17 个 API、15 个错误码、17 个测试用例）和客户端 UI（M3-01 完成），但缺少运营监控指标和统计 API，运营团队无法实时监控经济系统运行状态（交易量、拍卖活跃度、货币流通量等）。

本轮任务参照 ops-service 已有的分析仪表盘框架（AnalyticsRepository、DashboardResponse、TrendResponse 等），扩展经济系统相关的运营监控指标和统计 API，闭合 M3 里程碑的经济系统运营监控能力。

## 任务目标

为经济系统补充完整的运营监控能力，覆盖：

1. **player-service 经济系统业务指标**：Prometheus metrics 埋点（交易、拍卖、钱包三大类）
2. **player-service 经济统计 API**：运营侧经济数据统计接口（交易统计、拍卖统计、货币流通统计）
3. **ops-service 经济仪表盘集成**：扩展分析仪表盘，新增经济系统统计面板
4. **测试覆盖**：为新增功能补充单元测试

## 执行步骤

### 步骤 1：player-service 经济系统 Prometheus metrics 埋点

1. 扩展 `services/player/app/core/metrics.py`，新增经济系统相关指标：
   - 交易类：`player_trades_created_total`、`player_trades_completed_total`、`player_trades_cancelled_total`、`player_trade_volume_coins_total`
   - 拍卖类：`auction_listings_created_total`、`auction_listings_sold_total`、`auction_bids_placed_total`、`auction_volume_coins_total`
   - 钱包类：`wallet_transactions_total`、`wallet_total_gold_supply`
2. 在对应 Repository 关键操作点埋点（创建交易、完成交易、取消交易、创建拍卖、成交、出价、钱包交易等）
3. 扩展 `test_health.py` 新增经济指标暴露测试

### 步骤 2：player-service 经济统计 API（运营侧）

1. 扩展 `EconomicRepository`（新增仓储层），实现以下统计查询：
   - 交易统计：按日/周/月统计交易量、交易金额、交易完成率
   - 拍卖统计：活跃挂单数、成交率、平均成交价、总成交额
   - 钱包统计：总货币供应量、人均持有量、交易笔数分布
   - 趋势数据：按时间维度的经济指标趋势
2. 新增 6 个运营侧 API 端点：
   - `GET /ops/economy/overview` - 经济系统概览
   - `GET /ops/economy/trades` - 交易统计列表
   - `GET /ops/economy/auctions` - 拍卖统计列表
   - `GET /ops/economy/wallets` - 钱包统计列表
   - `GET /ops/economy/trends` - 经济指标趋势
   - `GET /ops/economy/top-traders` - 活跃交易者排行
3. 新增 6 个经济系统相关错误码
4. 新增对应 Schema（EconomicOverview、TradeStatsItem、AuctionStatsItem、WalletStatsItem、EconomicTrendPoint、TopTraderItem 等）
5. 新增审计动作常量和业务指标
6. 新增 Scope：`economy:read`

### 步骤 3：ops-service 经济仪表盘集成

1. 扩展 `ops/app/schemas/ops.py`，新增经济系统相关 Schema：
   - `EconomicOverview`、`TradeStatsItem`、`AuctionStatsItem`、`WalletStatsItem`、`EconomicTrendPoint`
2. 扩展 `ops/app/repositories/dashboard_repo.py`，新增经济系统统计数据方法
3. 扩展 `ops/app/api/routes.py`，新增 3 个经济仪表盘 API：
   - `GET /ops/analytics/dashboard/economy/overview` - 经济概览
   - `GET /ops/analytics/dashboard/economy/trends` - 经济趋势
   - `GET /ops/analytics/dashboard/economy/trade-stats` - 交易统计
4. 扩展 `DashboardMetrics` 模型，新增经济系统指标字段
5. 新增审计动作常量
