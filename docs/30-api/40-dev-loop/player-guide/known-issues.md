## 反馈方式

如你遇到的问题不在上述列表中，请通过以下方式反馈：

1. **游戏内反馈**：使用游戏内反馈功能提交问题（主菜单 → 设置 → 反馈）
2. **官方社区**：在官方社区发帖反馈（如有）

反馈时请提供：
- 问题描述（详细说明遇到的问题）
- 操作步骤（如何重现问题）
- 错误信息（如有错误代码或提示）
- 截图/录像（如有）
- 设备信息（操作系统、硬件配置）
