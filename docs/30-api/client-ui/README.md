# 客户端交互稿与界面流文档

> 文档状态：active
> 适用阶段：当前
> 维护要求：持续维护

## 适用范围

- 适用于描述 Godot 客户端的界面布局、交互逻辑和页面流转关系
- 适用于前端/客户端开发人员理解和实现界面功能
- 适用于产品设计人员确认界面交互设计
- 不替代 Godot 场景文件和脚本代码，而是提供设计说明和参考

## 当前定位

- 本文档是客户端界面的设计说明文档，用于回答"界面长什么样、怎么交互、页面怎么流转"
- 本文档聚焦界面布局、信息结构和交互逻辑，不单独定义具体的技术实现细节
- 当设计说明与实际实现冲突时，以代码实现为准，但应更新本文档保持同步

## 技术栈

- 游戏引擎：Godot 4
- 脚本语言：typed GDScript
- UI 框架：Godot Control 节点

## 设计原则

1. **一致性**：界面风格、交互模式、视觉元素保持一致
2. **清晰性**：信息层次清晰，操作反馈明确
3. **可用性**：关键操作易于发现和执行
4. **响应性**：界面状态变化及时反馈给用户
5. **可访问性**：界面元素大小和间距适合操作
