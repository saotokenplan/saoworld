## 二、投票状态迁移

### 投票周期状态机

```
draft → scheduled → open → closed → finalized
                                 ↑
                                 └── 管理员可重新开放（需审计）
```

| 状态 | 说明 | 允许操作 |
|------|------|----------|
| draft | 草稿 | 修改、计划 |
| scheduled | 已计划 | 修改、开放 |
| open | 开放投票 | 关闭 |
| closed | 已关闭 | 结算（finalize）、重新开放 |
| finalized | 已结算 | 无 |

### 玩家投票状态

```
未投票 → 已投票
   ↑
   └── 新投票周期开始时重置
```

## 三、任务状态迁移

### 任务生命周期

```
available → active → completed
               ↓
           failed
```

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| available | 可用 | 任务创建、前置任务完成 |
| active | 进行中 | 玩家接取任务 |
| completed | 已完成 | 所有目标达成 |
| failed | 失败 | 任务超时、目标失败 |

### 任务目标状态

```
未完成 → 完成
```

每个任务包含多个目标，所有目标完成后任务状态变为 `completed`。

## 四、区域状态迁移

### 区域生命周期

```
locked → active → unstable → archived
```

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| locked | 锁定 | 初始状态，未解锁 |
| active | 活跃 | 玩家解锁区域 |
| unstable | 不稳定 | 内容更新、投票结果影响 |
| archived | 已归档 | 区域内容过时 |

### 区域解锁条件

1. 完成前置章节任务
2. 达到指定等级
3. 获得足够声望
4. 完成特定投票结果

## 五、NPC对话状态迁移

### 对话流程

```
开始 → 对话节点1 → 对话节点2 → ... → 结束
         ↓            ↓
      选项1-4      选项1-4
```

### 对话选项类型

| 类型 | 说明 | 后续动作 |
|------|------|----------|
| 普通选项 | 继续对话 | 进入下一个对话节点 |
| 任务选项 | 触发任务接取 | 显示任务确认对话框 |
| 结束选项 | 结束对话 | 返回NPC列表 |

## 六、场景加载流程

### 场景切换流程

```
当前场景 → 保存状态 → 加载目标场景 → 初始化场景 → 显示场景
```

### 场景加载状态

| 状态 | 说明 |
|------|------|
| loading | 加载中 |
| loaded | 已加载 |
| ready | 可交互 |

## 七、数据同步流程

### 离线→在线同步

```
本地存档 → 连接服务器 → 上传变更 → 下载最新数据 → 更新本地状态
```

### 自动同步时机

1. 游戏启动时
2. 进入新区域时
3. 完成任务时
4. 投票提交后
5. 定期同步（每5分钟）

## 八、错误处理流程

### API请求错误处理

```
API请求 → 成功 → 更新界面
         ↓
      失败
         ↓
   判断错误类型
         ↓
   ┌────┴────┐
   │         │
   ▼         ▼
认证错误   其他错误
   │         │
   ▼         ▼
重新登录   显示错误信息
            ↓
         重试/忽略
```

### 网络错误处理

```
网络请求 → 成功 → 继续流程
           ↓
        超时/失败
           ↓
     重试（最多3次）
           ↓
     仍失败
           ↓
     使用本地缓存
           ↓
     显示离线提示
```
