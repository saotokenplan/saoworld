## 界面概述

主菜单是游戏的入口界面，提供核心功能入口和游戏信息展示。

## 界面元素

### 游戏信息区

| 元素 | 类型 | 说明 |
|------|------|------|
| Logo | Sprite | 游戏 Logo 图标 |
| 标题 | Label | 游戏名称"世界重塑" |
| 副标题 | Label | 游戏世界观时间"重建纪元 87 年" |

### 功能入口区

| 按钮 | 触发动作 | 说明 |
|------|----------|------|
| 投票 | 切换到投票面板场景 | 查看当前投票周期和提交投票 |
| 世界地图 | 切换到世界地图场景 | 查看和选择游戏区域 |
| 任务 | 切换到任务面板场景 | 查看任务列表和接取任务 |
| 设置 | 打开设置面板 | 游戏设置（音频、画面等） |
| 退出 | 退出游戏 | 关闭游戏窗口 |

### 版本信息区

| 元素 | 类型 | 说明 |
|------|------|------|
| 版本号 | Label | 游戏版本号 |

## 交互逻辑

### 入口点击

1. 用户点击功能入口按钮
2. 触发场景切换信号
3. 加载目标场景
4. 隐藏主菜单场景

### 返回主菜单

各功能界面的"返回"按钮触发场景切换回主菜单。

## 数据依赖

| 数据 | 来源 | 说明 |

| 玩家状态 | `GameState` | 玩家登录状态、章节进度等 |
