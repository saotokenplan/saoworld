# NPC交互界面设计

> 文档状态：active
> 适用阶段：当前
> 维护要求：持续维护

## 界面概述

NPC交互界面包含两个核心部分：NPC列表（查看区域内NPC）和对话界面（与NPC交互、接取任务）。

### 交互逻辑

#### 开始对话

1. 用户点击NPC的"对话"按钮
2. 加载NPC的对话树数据
3. 显示第一段对话内容和选项

#### 选择对话选项

1. 用户点击对话选项
2. 根据选项ID加载下一段对话
3. 更新对话框内容和选项列表
4. 如果选项触发任务接取，显示任务接取确认

#### 多段对话

1. 对话数据以对话树形式组织
2. 每个对话节点包含对话文本和选项列表
3. 选项指向不同的后续对话节点
4. 最后一个对话节点结束对话

#### 任务接取

1. 特定对话选项触发任务接取
2. 显示任务信息和接取确认对话框
3. 用户确认后接取任务
4. 对话继续或结束

## 数据结构

**NPC数据**：

| 字段 | 类型 | 说明 |
|------|------|------|
| npc_id | String | NPC唯一ID |
| name | String | NPC名称 |
| faction | String | 所属阵营 |
| status | String | 对玩家态度 |
| avatar | String | 头像资源路径 |
| dialog_tree | Dictionary | 对话树数据 |
| available_quests | Array | 可接取任务ID列表 |

**对话节点数据**：

| 字段 | 类型 | 说明 |
|------|------|------|
| dialog_id | String | 对话节点ID |
| text | String | 对话文本 |
| options | Array | 选项列表 |

**对话选项数据**：

| 字段 | 类型 | 说明 |
|------|------|------|
| option_id | String | 选项ID |
| text | String | 选项文本 |
| next_dialog_id | String | 下一个对话节点ID |
| trigger_quest_id | String | 触发的任务ID（可选） |
