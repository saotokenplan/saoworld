# 任务面板界面设计

> 文档状态：active
> 适用阶段：当前
> 维护要求：持续维护

## 界面概述

任务面板展示玩家的任务列表，包括可接取任务、进行中任务和已完成任务。玩家可以查看任务详情、接取任务、追踪任务进度。

## 界面元素

### 过滤标签

| 标签 | 过滤条件 | 说明 |
|------|----------|------|
| 全部 | 无过滤 | 显示所有任务 |
| 可用 | status = available | 可接取的任务 |
| 进行 | status = active | 进行中的任务 |
| 完成 | status = completed | 已完成的任务 |

### 任务列表区

| 元素 | 类型 | 说明 |
|------|------|------|
| 任务卡片 | Panel | 任务信息展示 |
| 任务标题 | Label | 任务名称 |
| 状态标签 | Label | 任务状态 |
| 目标描述 | Label | 任务目标 |
| 进度信息 | Label | 目标完成进度 |
| 奖励信息 | Label | 任务奖励 |

### 分页区

| 元素 | 类型 | 说明 |
|------|------|------|
| 分页按钮 | Button | 上一页/下一页 |
| 页码信息 | Label | 当前页码和总页数 |

## 交互逻辑

### 加载任务数据

1. 进入面板时调用 `PlayerManager.fetch_quests()`
2. 根据过滤标签显示对应状态的任务
3. 默认显示"全部"任务

### 任务详情

1. 用户点击任务卡片
2. 展开任务详情（标题、描述、目标、奖励）
3. 显示"接取任务"或"追踪任务"按钮

### 接取任务

1. 任务状态为 `available` 时显示"接取任务"按钮
2. 用户点击按钮调用 `PlayerManager.accept_quest()`
3. 接取成功后任务状态变为 `active`
4. 更新任务列表显示

### 任务进度追踪

1. 进行中任务显示进度条
2. 每个目标显示完成状态
3. 任务完成时状态变为 `completed`
4. 显示奖励获取提示

## 数据结构

**任务数据**：

| 字段 | 类型 | 说明 |
|------|------|------|
| quest_id | String | 任务唯一ID |
| title | String | 任务标题 |
| description | String | 任务描述 |
| status | String | available / active / completed / failed |
| objectives | Array | 目标列表 |
| rewards | Dictionary | 奖励信息 |
| chapter_id | String | 所属章节 |
| region_id | String | 所属区域 |

**目标数据**：

| 字段 | 类型 | 说明 |
|------|------|------|
| objective_id | String | 目标唯一ID |
| description | String | 目标描述 |
| completed | bool | 是否已完成 |

**奖励数据**：

| 字段 | 类型 | 说明 |
|------|------|------|
| gold | int | 金币奖励 |
| exp | int | 经验奖励 |
| reputation | Dictionary | 声望奖励 |
