# 投票界面设计

> 文档状态：active
> 适用阶段：当前
> 维护要求：持续维护

## 界面概述

投票界面包含三个核心面板：投票面板（提交投票）、投票结果面板（展示结果）、投票历史面板（查看历史）。

## 一、投票面板（VotingPanel）

### 界面布局

```
┌─────────────────────────────────────────────┐
│  [返回按钮]              投票                │
├─────────────────────────────────────────────┤
│                                             │
│           [投票周期标题]                     │
│                                             │
│           [投票周期描述]                     │
│                                             │
│  ┌───────────────────────────────────────┐  │
│  │    候选项 1 - 标题                    │  │
│  │    候选项 1 - 描述                    │  │
│  │                                       │  │
│  │    候选项 2 - 标题                    │  │
│  │    候选项 2 - 描述                    │  │
│  │                                       │  │
│  │    候选项 3 - 标题                    │  │
│  │    候选项 3 - 描述                    │  │
│  └───────────────────────────────────────┘  │
│                                             │
│           [提交投票按钮]                    │
│                                             │

└─────────────────────────────────────────────┘
```

### 界面元素

| 元素 | 类型 | 说明 |
|------|------|------|
| 返回按钮 | Button | 返回主菜单 |
| 周期标题 | Label | 当前投票周期标题 |
| 周期描述 | Label | 当前投票周期描述 |
| 候选项列表 | VBoxContainer | 候选按钮列表 |
| 提交按钮 | Button | 提交投票（选中候选项后可用） |
| 状态提示 | Label | 操作提示和错误信息 |

### 交互逻辑

#### 加载投票数据

1. 进入投票面板时自动调用 `VoteManager.fetch_current_vote()`
2. 加载成功后显示周期信息和候选项列表
3. 加载失败时显示错误提示

#### 选择候选项

1. 用户点击候选项按钮
2. 按钮变为选中状态（toggle_mode）
3. 其他按钮取消选中
4. 提交按钮变为可用

#### 提交投票

1. 用户点击"提交投票"按钮
2. 调用 `VoteManager.submit_vote(selected_candidate_id)`
3. 提交成功：更新 `has_voted` 状态，显示成功提示
4. 提交失败：显示错误信息

#### 已投票状态

1. 已投票时，候选项显示票数和占比
2. 提交按钮变为禁用状态，显示"您已投票"
3. 状态提示变为"您已投票，以下是当前投票结果预览"

### 数据结构

**候选项数据**：

| 字段 | 类型 | 说明 |
|------|------|------|
| candidate_id | String | 候选项唯一ID |
| title | String | 候选项标题 |
| description | String | 候选项描述 |
| vote_count | int | 已获票数 |
| is_winner | bool | 是否为获胜者 |

## 二、投票结果面板（VoteResultPanel）

### 界面布局

```
┌─────────────────────────────────────────────┐
│  [返回按钮]              投票结果            │
├─────────────────────────────────────────────┤
│                                             │
│           [投票周期标题]                     │
│                                             │
│  ┌───────────────────────────────────────┐  │
│  │  总票数：1234                         │  │
│  │                                       │  │
│  │  候选项 1 ─███████████████ 65%       │  │
│  │  候选项 2 ─███████        25%       │  │
│  │  候选项 3 ─███            10%       │  │
│  │                                       │  │
│  │  🏆 获胜者：候选项 1                    │  │
│  └───────────────────────────────────────┘  │
│                                             │
│  预计影响区域：铁卫城周边                   │
│  预计上线周期：下一周                       │
│                                             │
│  上一轮投票结果：[查看详情]                 │
└─────────────────────────────────────────────┘
```

### 界面元素

| 元素 | 类型 | 说明 |
|------|------|------|
| 返回按钮 | Button | 返回主菜单 |
| 周期标题 | Label | 投票周期标题 |
| 总票数 | Label | 当前周期总票数 |
| 进度条 | ProgressBar | 各候选项票数占比 |
| 获胜者标识 | Label | 获胜候选项高亮显示 |
| 影响信息 | Label | 预计影响区域和上线周期 |
| 历史结果链接 | Button | 查看上一轮投票结果落地情况 |

### 交互逻辑

1. 投票结算完成后自动进入结果面板
2. 计算各候选项占比并渲染进度条
3. 高亮显示获胜候选项
4. 显示投票结果的影响信息

## 三、投票历史面板（VoteHistoryPanel）

### 界面布局

```
┌─────────────────────────────────────────────┐
│  [返回按钮]              投票历史            │
├─────────────────────────────────────────────┤
│                                             │
│  ┌───────────────────────────────────────┐  │
│  │  投票周期 1                              │  │
│  │  状态：已完成    票数：1234             │  │
│  │  获胜者：候选项 A                        │  │
│  └───────────────────────────────────────┘  │
│                                             │
│  ┌───────────────────────────────────────┐  │
│  │  投票周期 2                              │  │
│  │  状态：进行中    票数：567              │  │
│  │  获胜者：-                              │  │
│  └───────────────────────────────────────┘  │
│                                             │
│           [上一页] [下一页]                 │
│           第 1/5 页                         │
└─────────────────────────────────────────────┘
```

### 界面元素

| 元素 | 类型 | 说明 |
|------|------|------|
| 返回按钮 | Button | 返回主菜单 |
| 历史列表 | VBoxContainer | 投票历史记录列表 |
| 周期卡片 | Panel | 单个投票周期信息 |
| 分页按钮 | Button | 上一页/下一页 |
| 页码信息 | Label | 当前页码和总页数 |

### 交互逻辑

1. 进入面板时调用 `VoteManager.fetch_history()`
2. 显示历史记录列表（默认每页 20 条）
3. 点击分页按钮切换页码
4. 点击周期卡片查看详细结果
