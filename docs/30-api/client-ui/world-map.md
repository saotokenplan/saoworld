# 世界地图界面设计

> 文档状态：active
> 适用阶段：当前
> 维护要求：持续维护

## 界面概述

世界地图界面展示游戏世界的区域分布，玩家可以查看区域信息、选择进入区域、了解区域状态。

## 界面元素

### 地图区域区

| 元素 | 类型 | 说明 |
|------|------|------|
| 区域卡片 | Panel | 显示区域名称和状态 |
| 状态标识 | Label | 区域状态（活跃/锁定/不稳定/已归档） |

### 区域详情区

| 元素 | 类型 | 说明 |
|------|------|------|
| 区域名称 | Label | 选中区域名称 |
| 区域类型 | Label | 核心常驻区域 / 扩展区域 |
| 势力信息 | Label | 主要势力 |
| 风险等级 | Label | 低/中/高 |
| 资源等级 | Label | 低/中/高 |
| 进入按钮 | Button | 进入选中区域 |

## 交互逻辑

### 加载区域数据

1. 进入地图时调用 `WorldManager.fetch_regions()`
2. 根据区域状态渲染不同样式的区域卡片
3. 默认选中第一个活跃区域

### 选择区域

1. 用户点击区域卡片
2. 更新选中状态（高亮显示）
3. 在详情区显示区域信息
4. 更新"进入区域"按钮状态

### 区域状态样式

| 状态 | 样式 | 说明 |
|------|------|------|
| active | 绿色边框 | 可进入的活跃区域 |
| locked | 灰色边框 + 锁图标 | 未解锁区域 |
| unstable | 黄色边框 + 警告图标 | 不稳定区域 |
| archived | 灰色半透明 | 已归档区域 |

### 进入区域

1. 用户点击"进入区域"按钮
2. 检查区域是否已解锁（`GameState.is_region_unlocked()`）
3. 未解锁时显示提示信息
4. 已解锁时切换到区域场景

## 数据结构

**区域数据**：

| 字段 | 类型 | 说明 |
|------|------|------|
| region_id | String | 区域唯一ID |
| name | String | 区域名称 |
| description | String | 区域描述 |
| type | String | 核心常驻 / 扩展 |
| status | String | locked / active / unstable / archived |
| faction | String | 主要势力 |
| risk_level | String | 低 / 中 / 高 |
| resource_level | String | 低 / 中 / 高 |
