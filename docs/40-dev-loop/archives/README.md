# 自动产物归档

> 文档状态：active
> 适用阶段：当前
> 维护要求：持续维护

## 目的

本目录用于收纳 `40-dev-loop/` 下不适合作为一级阅读入口的高频自动产物，降低主目录噪音，同时保留审计与回溯线索。

## 适用范围

- 适用于自动规划、自动执行摘要、自动状态快照等批量生成文档。
- 适用于需要按日期回查某一轮自动流程输出的场景。
- 不替代 `auto-progress-log.md`、周报或阶段总结等面向阅读的入口文档。

## 当前定位

- 本目录是研发闭环层下的归档子目录。
- 本目录保留审计价值，但不作为默认阅读路径。
- 归档文档允许保留历史路径、历史命名和当时的上下文描述。

## 当前结构

- `auto-generated/2026-07/`
  - 2026 年 7 月产生的自动规划、执行摘要和状态快照

## 使用建议

1. 优先从 `docs/40-dev-loop/README.md` 和 `auto-progress-log.md` 进入
2. 只有在需要追溯某轮自动输出时，再进入本目录
3. 如新增新月份归档，按 `YYYY-MM` 继续扩展

## 与其他文档的关系

- `docs/40-dev-loop/README.md`
  - 研发闭环总入口
- `docs/40-dev-loop/auto-progress-log.md`
  - 面向当前阅读的累计进展入口
