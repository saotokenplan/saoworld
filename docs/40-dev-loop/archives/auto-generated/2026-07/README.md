# 2026-07 自动产物索引

> 文档状态：active
> 适用阶段：归档查阅
> 维护要求：持续维护

## 目的

本目录收纳 2026 年 7 月产生的自动化文档产物，并按产物类型拆分，降低单目录堆叠带来的检索成本。

## 当前结构

- `plan/`
  - 自动计划文档，主要记录某轮自动任务的目标、步骤和涉及文件
- `execution/`
  - 自动执行摘要，主要记录完成内容、修改结果和验证结论
- `status/`
  - 自动状态快照，主要记录某时点的项目状态或无新工作结束报告
- `analysis/`
  - 不适合归入标准 `plan / execution / status` 的异常样本或专题分析

## 使用建议

1. 需要追溯某次自动计划时，进入 `plan/`
2. 需要查看某轮执行结果时，进入 `execution/`
3. 需要查看项目状态快照时，进入 `status/`
4. 只有遇到命名异常或专题分析时，再进入 `analysis/`

## 说明

- 本目录保留历史命名，不在本轮强制重命名旧文件。
- 历史文件正文中可能仍引用迁移前路径，这些内容作为审计记录保留。
- 后续若重构自动生成器，建议直接输出到对应子目录，而不是先堆到月份根目录。
