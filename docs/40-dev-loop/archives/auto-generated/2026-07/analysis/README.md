# 分析归档入口

> 文档状态：active
> 适用阶段：归档查阅
> 维护要求：持续维护

## 目的

本目录用于归档不适合直接归入计划、执行或状态快照的专题分析材料、异常样本和补充分析结果。

## 当前定位

- 本目录是 `docs/40-dev-loop/archives/auto-generated/2026-07/` 下的分析归档子目录。
- 本目录内容通常是专题分析或异常样本，阅读频次低于 `plan/`、`execution/` 和 `status/`。
- 若分析结论后来进入正式规范或主入口，应以正式文档为准。

## 使用建议

1. 只有在需要追溯专题分析或异常样本时，再进入本目录。
2. 需要对应的计划或执行上下文时，联动查看同月份其他归档子目录。
3. 需要当前正式治理结论时，回到 `docs/00-governance/` 与 `docs/40-dev-loop/` 主入口。
