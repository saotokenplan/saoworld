## 具体执行步骤

### 步骤 1：创建 tools/content_check/ 目录和基础模块

- 创建 `tools/content_check/config.py` - 检查配置（阈值、规则等）

### 步骤 2：实现世界一致性检查工具

- 创建 `tools/content_check/world_consistency.py`
- 检查项：
  - 阵营关系不与世界观根设定冲突
  - NPC 身份不越过章节认知边界
  - 聚落资源与地貌和势力匹配
  - 事件影响不直接改写主线终局
  - schema_version 字段存在且合法
- 输入：内容包数据（JSON/字典）+ 世界观规则
- 输出：检查结果（通过/失败、问题列表、评分）

### 步骤 3：实现数值平衡检查工具

- 创建 `tools/content_check/reward_boundary.py`
- 检查项：
  - 奖励不突破章节上限
  - 敌人强度不超出区域允许区间
  - 重复支线累计收益不形成刷取漏洞
  - 资源刷新在服务器配置区间内
  - 经验值/等级曲线合理
- 输入：内容包数据 + 数值配置
- 输出：检查结果（通过/失败、问题列表、评分）

### 步骤 4：实现内容安全检查工具

- 创建 `tools/content_check/content_safety.py`
- 检查项：
  - 敏感词检测（命中直接驳回）
  - 高风险主题识别（进入人工复核）
  - 目标年龄层适配检查
  - 暴力/色情/政治敏感内容检测
- 使用关键词匹配 + 规则引擎（初期用关键词列表，后续可扩展）
- 输入：内容文本数据
- 输出：检查结果（通过/失败/人工复核、风险等级、问题列表）

### 步骤 5：实现重复度检查工具

- 创建 `tools/content_check/duplication.py`
- 检查项：
  - 同章节 NPC 设定相似度阈值 ≤ 0.8
  - 同区域支线骨架复用比例 ≤ 0.6
  - 文案段落重复率 ≤ 0.3
- 使用文本相似度算法（Jaccard相似度、编辑距离等）
- 输入：内容包数据 + 已有内容数据
- 输出：检查结果（通过/失败、重复项列表、评分）
