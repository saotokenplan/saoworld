实现三层 Loop（规则改进 Loop）的核心基础设施：

- 二层 Loop（门禁改进 Loop）：结构化日志采集、失败签名提取、失败聚类、缺口分类、Gate Improvement Issue 自动生成

三层 Loop 的核心功能：
1. 采集二层 Issue 的处理反馈（被采纳/被拒绝/讨论内容/最终效果）
2. 总结"哪些规则提出了高价值 issue，哪些规则误报/漏报"
3. 输出 Rule Improvement PR（更新规则、阈值、分类器、样本集）
4. 验证规则改进效果
