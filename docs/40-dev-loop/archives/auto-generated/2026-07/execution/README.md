# 执行归档入口

> 文档状态：active
> 适用阶段：归档查阅
> 维护要求：持续维护

## 目的

本目录用于归档自动执行摘要，帮助读者回溯某轮自动推进实际做了什么、改了哪些内容、留下了什么验证结论。

## 当前定位

- 本目录是 `docs/40-dev-loop/archives/auto-generated/2026-07/` 下的执行归档子目录。
- 历史执行摘要保留生成时的原始上下文，不作为当前项目状态或目录结构的权威来源。
- 需要当前阶段判断时，应回到 `docs/00-governance/project-status.md` 和 `docs/40-dev-loop/README.md`。

## 使用建议

1. 需要追溯某轮自动执行做了哪些修改时，查本目录。
2. 需要对应计划文档时，联动查看同月份的 `plan/`。
3. 需要最近状态快照时，转到同月份的 `status/`。
