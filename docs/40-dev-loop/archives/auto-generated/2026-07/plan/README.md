# 计划归档入口

> 文档状态：active
> 适用阶段：归档查阅
> 维护要求：持续维护

## 目的

本目录用于归档自动生成的计划文档，帮助读者回溯某轮自动推进在开始执行前如何界定目标、步骤和涉及文件。

## 当前定位

- 本目录是 `docs/40-dev-loop/archives/auto-generated/2026-07/` 下的计划归档子目录。
- 历史文件保留原始命名和当时的上下文，不在本轮强制追改旧正文。
- 若历史正文包含旧路径或旧阶段判断，应视为审计快照，而不是当前权威入口。

## 使用建议

1. 需要查某轮任务最初怎么规划时，优先查本目录。
2. 需要看执行结果时，转到同月份的 `execution/`。
3. 需要看最新治理口径时，回到 `docs/00-governance/` 与当前根入口文档。
