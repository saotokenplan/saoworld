## 任务目标与背景

**背景**：项目当前处于内容发布与验证阶段，核心目标是完成首期内容包灰度发布，验证端到端玩法流程。API 规范与服务端实现基本对齐，但 OpenAPI 草案中仍有部分预留错误码（如 `TOKEN_EXPIRED`）尚未落地。

**问题识别**：

2. OpenAPI 草案与服务端实现之间存在一致性缺口，影响客户端 SDK 生成和文档完整性

**目标**：将预留错误码（`TOKEN_EXPIRED`）落地到 OpenAPI 草案，更新错误码文档，确保 API 规范与服务端实现完全对齐，为首期内容包灰度发布做好准备。
