## 任务目标与背景

### 目标
完善 gateway-service 的路由映射配置，添加 player-service 和 ops-service 的代理路由支持，确保所有 8 个后端服务都能通过 API 网关统一访问。

### 背景
项目当前处于内容发布与验证阶段，核心目标是完成首期内容包灰度发布，验证端到端玩法流程。

当前 gateway-service 只配置了 5 个服务的路由映射：
- vote-service
- world-service
- content-service
- generation-service
- review-service

缺少以下 2 个核心服务的路由映射和配置：
- player-service（玩家信息、任务、区域解锁）
- ops-service（运营后台、仪表盘、系统状态）

这导致：
1. 玩家接口（任务查询、玩家信息等）无法通过网关统一访问
2. 运营接口无法通过网关统一访问
3. 网关的限流、认证、追踪等中间件无法覆盖全部服务
4. 端到端集成测试无法通过网关完整验证所有服务
