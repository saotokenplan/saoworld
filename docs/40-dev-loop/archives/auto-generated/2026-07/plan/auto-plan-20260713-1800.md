## 任务目标与背景

Sprint 4 S4-01「投票结果落地展示」已完整交付（功能+测试）。Sprint 4 的下一个 P0 任务是 S4-02「投票讨论区」。

投票讨论区是提升玩家参与感和社区讨论度的核心功能：
- 每个投票周期关联一个讨论区
- 玩家可发表观点、点赞、回复
- 讨论按热度排序
- 增强投票的社交属性和玩家粘性

本轮任务目标：实现投票讨论区的完整后端能力（vote-service）和 Godot 客户端 UI，包含讨论发布、点赞、回复、列表查询等核心功能。

## 具体执行步骤

### 步骤 1：vote-service 数据模型设计

在 `services/vote/app/domain/models.py` 中新增：
- `VoteDiscussion`（讨论主帖表）：discussion_id, vote_cycle_id, player_id, content, like_count, reply_count, status, created_at
- `VoteDiscussionReply`（讨论回复表）：reply_id, discussion_id, player_id, content, like_count, status, created_at
- `VoteDiscussionLike`（点赞记录表）：like_id, discussion_id, reply_id, player_id, created_at（唯一索引防重复点赞）

CHECK 约束：
- `content` 长度限制（1-500字）
- `status` 合法值：active, hidden, deleted

外键约束：
- `vote_cycle_id` → `vote_cycles.vote_cycle_id`（ON DELETE RESTRICT）
- `discussion_id` → `vote_discussions.discussion_id`（ON DELETE CASCADE）

索引：
- `vote_discussions_cycle_id_idx`（vote_cycle_id, created_at DESC）
- `vote_discussions_like_count_idx`（vote_cycle_id, like_count DESC）
- `vote_discussion_replies_discussion_id_idx`（discussion_id, created_at ASC）
- `vote_discussion_likes_unique_idx` UNIQUE（player_id, discussion_id, reply_id）

### 步骤 2：vote-service Repository 层实现

在 `services/vote/app/repositories/` 新增 `discussion_repo.py`：
- `list_discussions(vote_cycle_id, sort_by, limit, offset)` - 讨论列表（支持按热度/时间排序）
- `get_discussion(discussion_id)` - 讨论详情
- `create_discussion(vote_cycle_id, player_id, content)` - 发布讨论
- `like_discussion(discussion_id, player_id)` - 点赞讨论（幂等，重复点赞取消）
- `unlike_discussion(discussion_id, player_id)` - 取消点赞
- `list_replies(discussion_id, limit, offset)` - 回复列表
- `create_reply(discussion_id, player_id, content)` - 发布回复
- `like_reply(reply_id, player_id)` - 点赞回复（幂等）
- `has_liked(player_id, discussion_id, reply_id)` - 检查是否已点赞

### 步骤 3：vote-service Schemas 层

在 `services/vote/app/schemas/vote.py` 中新增：
- `VoteDiscussionResponse` - 讨论响应
- `VoteDiscussionReplyResponse` - 回复响应
- `DiscussionListResponse` - 讨论列表响应（带分页）
- `ReplyListResponse` - 回复列表响应（带分页）
- `CreateDiscussionRequest` - 发布讨论请求
- `CreateReplyRequest` - 发布回复请求

### 步骤 4：vote-service API 路由层

在 `services/vote/app/api/routes.py` 中新增：

**玩家接口（votes:read / votes:submit scope）：**
- `GET /api/v1/votes/discussions/{vote_cycle_id}` - 获取讨论列表
- `POST /api/v1/votes/discussions/{vote_cycle_id}` - 发布讨论
- `POST /api/v1/votes/discussions/{discussion_id}/like` - 点赞讨论
- `DELETE /api/v1/votes/discussions/{discussion_id}/like` - 取消点赞
- `GET /api/v1/votes/discussions/{discussion_id}/replies` - 获取回复列表
- `POST /api/v1/votes/discussions/{discussion_id}/replies` - 发布回复
- `POST /api/v1/votes/replies/{reply_id}/like` - 点赞回复
- `DELETE /api/v1/votes/replies/{reply_id}/like` - 取消回复点赞

**运营接口（ops 角色）：**
- `DELETE /api/v1/ops/discussions/{discussion_id}` - 隐藏/删除讨论
- `DELETE /api/v1/ops/replies/{reply_id}` - 隐藏/删除回复
