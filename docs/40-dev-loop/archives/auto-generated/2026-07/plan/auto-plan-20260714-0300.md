## 任务目标与背景

### 目标

实现投票进度实时更新功能，让玩家在投票期间能够实时查看各候选项的票数变化，增强参与感和社区讨论氛围。

### 背景

当前投票系统仅支持提交投票和查看最终结果，投票期间玩家无法了解投票进度。在投票周期开放期间提供实时进度展示，能够：
- 提高玩家参与度和留存率
- 促进社区讨论
- 增加投票过程的透明度
- 为后续投票结果可视化奠定基础

### 需求来源

Sprint 4 S4-03「投票进度实时更新」，项目每日进展报告（2026-07-13）中标记为"未开始"。

## 具体执行步骤

### 步骤 1：vote-service 新增投票进度查询 API

**目标**：提供投票周期开放期间的实时进度数据查询接口

**变更文件**：
- `services/vote/app/api/routes.py` - 新增进度查询路由
- `services/vote/app/schemas/vote.py` - 新增进度响应 Schema
- `services/vote/app/repositories/vote_repo.py` - 新增进度查询方法
- `services/vote/app/core/metrics.py` - 新增进度查询指标

**实现内容**：
1. 新增 `GET /api/v1/votes/current/progress` 接口
2. 返回当前开放投票周期的各候选项票数、占比、领先者
3. 支持按 `vote_cycle_id` 查询指定投票周期进度

### 步骤 2：vote-service 新增投票进度事件发布

**目标**：投票提交后发布进度更新事件，支持实时推送

**变更文件**：
- `services/vote/app/core/event_publisher.py` - 新增进度事件发布
- `services/vote/app/api/routes.py` - 投票提交后发布进度事件

**实现内容**：
1. 新增事件类型 `vote.progress.updated`
2. 投票提交成功后发布进度更新事件
3. 事件包含当前投票周期的进度快照

### 步骤 3：客户端 VoteManager 实现进度轮询

**目标**：客户端定期轮询投票进度并触发信号通知

**变更文件**：
- `game/scripts/autoload/vote_manager.gd` - 新增进度轮询方法和信号

**实现内容**：
1. 新增 `progress_poll_interval` 配置（默认 30 秒）
2. 新增 `fetch_vote_progress()` 方法
3. 新增 `vote_progress_updated` 信号
4. 新增 `start_progress_polling()` / `stop_progress_polling()` 方法
5. 新增进度数据结构（各候选票数、占比、领先者）

### 步骤 4：客户端 VotingPanel 实时进度展示

**目标**：投票面板展示实时进度

**变更文件**：
- `game/scenes/ui/voting/voting_panel.tscn` - 新增进度展示 UI 节点
- `game/scripts/ui/voting/voting_panel.gd` - 新增进度展示逻辑

**实现内容**：
1. 每个候选项显示当前票数和百分比
2. 显示领先候选项高亮标识
3. 显示总投票数
4. 绑定 `vote_progress_updated` 信号更新 UI

### 步骤 5：编写测试用例
