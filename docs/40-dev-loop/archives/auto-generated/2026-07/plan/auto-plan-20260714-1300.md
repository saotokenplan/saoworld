## 任务目标与背景

### 目标

实现公会聊天系统，支持公会成员之间的群聊功能，为 Sprint 5 社区基础功能的社交能力补全闭环。

Sprint 5 社区基础功能阶段，S5-01 好友系统、S5-02 私聊系统、S5-03 公会系统基础、S5-05 社交数据 API 均已完成。S5-04 公会聊天作为 P1 项，是社区功能的重要组成部分，为公会成员提供群聊交流能力。

### 需求来源

`docs/10-requirements/需求迭代计划.md` Sprint 5 S5-04「公会聊天」，验收标准：公会成员群聊。

## 具体执行步骤

### 步骤 1：player-service 数据模型（guild_messages 表）

**目标**：定义公会消息数据模型。

**变更文件**：
- `services/player/app/domain/models.py` - 新增 GuildMessage 模型

**实现内容**：
1. 新增 `guild_messages` 表，包含字段：
   - `message_id`：UUID 主键
   - `guild_id`：公会ID（外键 → guilds）
   - `sender_id`：发送者玩家ID（外键 → players）
   - `content`：消息内容（TEXT，最大 500 字符）
   - `is_read`：是否已读（BOOLEAN，默认 FALSE）
   - `created_at`：创建时间
2. CHECK 约束：length(content) > 0 AND length(content) <= 500
3. 复合索引：(guild_id, created_at DESC) 支持按时间倒序查询

### 步骤 2：GuildMessageRepository 仓储层实现

**目标**：实现公会消息的数据访问逻辑。

**变更文件**：
- `services/player/app/repositories/guild_message_repo.py` - 新建文件

**实现内容**：
1. `send_message` - 发送公会消息（检查玩家是否在公会）
2. `get_guild_messages` - 获取公会消息列表（分页，按时间倒序）
3. `mark_messages_as_read` - 批量标记消息已读
4. `get_unread_count` - 获取未读消息数
5. `delete_message` - 删除消息（仅发送者或会长权限）
6. `get_recent_messages` - 获取最近 N 条消息

### 步骤 3：API 接口实现

**目标**：实现公会聊天系统的 RESTful API。

**变更文件**：
- `services/player/app/api/routes.py` - 新增公会消息相关路由
- `services/player/app/schemas/player.py` - 新增公会消息相关 Schema
- `services/player/app/core/deps.py` - 新增公会消息相关 Scope
- `services/player/app/schemas/auth.py` - 新增 GUILD_MESSAGES_READ/WRITE Scope
- `services/player/app/core/errors.py` - 新增公会消息相关错误码
- `services/player/app/core/metrics.py` - 新增公会消息相关指标
- `services/player/app/repositories/audit_repo.py` - 新增公会消息审计动作

**API 接口**：
- `POST /api/v1/player/guilds/{guild_id}/messages` - 发送公会消息（Scope: guild:write）
- `GET /api/v1/player/guilds/{guild_id}/messages` - 获取公会消息列表（Scope: guild:read）
- `POST /api/v1/player/guilds/{guild_id}/messages/read` - 标记消息已读（Scope: guild:read）
- `GET /api/v1/player/guilds/{guild_id}/messages/unread-count` - 获取未读消息数（Scope: guild:read）
- `DELETE /api/v1/player/guilds/{guild_id}/messages/{message_id}` - 删除消息（Scope: guild:write）

**错误码**：
- `GUILD_NOT_FOUND` - 公会不存在
- `NOT_IN_GUILD` - 玩家未加入公会
- `MESSAGE_TOO_LONG` - 消息内容过长
- `MESSAGE_EMPTY` - 消息内容为空
- `MESSAGE_NOT_FOUND` - 消息不存在
- `CANNOT_DELETE_OTHER_MESSAGE` - 不能删除他人消息

**业务指标**：
- `guild_messages_sent_total` - 公会消息发送数
- `guild_messages_read_total` - 公会消息已读数
