## 任务目标与背景

### 目标

实现怪物生成模板系统，包括：1）generation-service 新增怪物数据适配器和 Jinja2 模板；2）world-service 新增怪物定义数据模型与 API；3）扩展质量评分器支持怪物评分；4）客户端新增怪物数据管理。

### 背景

Sprint 7 S7-01「第二章区域内容」和 S7-02「装备系统」已完成。S7-03「怪物生成模板」为 P0 项，依赖 S2-01（LLM服务接入，已完成），验收标准为"AI生成怪物属性、行为模式"。为后续 S7-04「Boss战设计」提供数据基础。

### 需求来源

`docs/10-requirements/需求迭代计划.md` Sprint 7 S7-03，验收标准：AI生成怪物属性、行为模式。

## 具体执行步骤

### 步骤 1：generation-service 新增怪物数据适配器

**目标**：创建 MonsterDataAdapter，将 AI 生成的怪物数据转换为 world-service 兼容格式。

**变更文件**：
- `services/generation/app/core/monster_data_adapter.py` - 新建

**实现内容**：
1. 必需字段：monster_key、name、monster_type、chapter_id、region_key、level、hp、attack、defense、speed、description、behavior_pattern、loot_table、skills
2. 完整度验证（0.95 门槛）
3. 默认值填充
4. Key 规范化（monster_ 前缀、region_ 前缀）

### 步骤 2：generation-service 新增怪物 Jinja2 模板

**目标**：创建怪物生成 Jinja2 模板文件。

**变更文件**：
- `services/generation/templates/monster/monster_base.jinja2` - 新建
- `services/generation/templates/monster/monster_boss.jinja2` - 新建

### 步骤 3：generation-service 扩展质量评分器

**目标**：新增 score_monster 方法。

**变更文件**：
- `services/generation/app/core/quality_scorer.py` - 修改

**实现内容**：
1. 必需字段检查
2. 怪物类型合法性（beast/humanoid/undead/mechanical/elemental/demon/dragon/boss）
3. 数值区间校验（level 1-60、hp > 0、attack > 0、defense >= 0）
4. 技能列表校验
5. 掉落表校验
6. ID 前缀校验

### 步骤 4：generation-service 扩展模板管理器和内容生成器

**目标**：新增怪物模板匹配和生成方法。

**变更文件**：
- `services/generation/app/core/template_manager.py` - 修改（新增 get_monster_template_by_type）
- `services/generation/app/core/content_generator.py` - 修改（新增 generate_monster 方法）

### 步骤 5：world-service 新增怪物定义数据模型

**目标**：新增 monster_definitions 表。

**变更文件**：
- `services/world/app/domain/models.py` - 修改

**实现内容**：
1. MonsterDefinition 模型：monster_id、monster_key、name、monster_type、chapter_id、region_key、level、hp、attack、defense、speed、description、behavior_pattern_jsonb、loot_table_jsonb、skills_jsonb、min_reputation、schema_version
2. CHECK 约束：monster_type 合法值、level >= 1、hp > 0、attack >= 0、defense >= 0、speed >= 0
3. 索引

### 步骤 6：world-service 新增怪物仓储层和 API

**目标**：新增怪物 CRUD 仓储和 API 端点。

**变更文件**：
- `services/world/app/repositories/monster_repo.py` - 新建
- `services/world/app/api/routes.py` - 修改
- `services/world/app/schemas/` - 新增怪物相关 Schema
- `services/world/app/core/metrics.py` - 新增怪物指标
- `services/world/app/core/errors.py` - 新增怪物错误码

**实现内容**：
1. MonsterRepository：列表、按ID/Key查询、创建、按区域查询
2. 玩家 API：怪物列表、怪物详情（monsters:read Scope）
3. 运营 API：创建怪物
4. 错误码：MONSTER_NOT_FOUND、MONSTER_KEY_EXISTS、INVALID_MONSTER_TYPE
5. 业务指标：world_monster_operations_total
6. 审计动作：monster_create
