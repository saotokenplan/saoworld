## 任务目标与背景

### 目标

实现区域Boss战系统，包括：1）world-service 新增Boss定义数据模型与API；2）generation-service 新增Boss生成模板和数据适配器；3）客户端扩展战斗系统支持Boss战特殊机制；4）创建两个第二章区域的Boss数据配置。

### 背景

Sprint 7 S7-01「第二章区域内容」、S7-02「装备系统」和 S7-03「怪物生成模板」已完成。S7-04「Boss战设计」为 P1 项，依赖 S7-03（怪物生成模板，已完成），验收标准为"区域Boss，特殊技能，丰厚奖励"。为玩家提供挑战性战斗体验和高级装备获取途径。

### 需求来源

`docs/10-requirements/需求迭代计划.md` Sprint 7 S7-04，验收标准：区域Boss，特殊技能，丰厚奖励。

## 具体执行步骤

### 步骤 1：world-service 新增Boss定义数据模型

**目标**：扩展 monster_definitions 表支持Boss类型，新增Boss专属字段。

**变更文件**：
- `services/world/app/domain/models.py` - 修改

**实现内容**：
1. 扩展 MonsterDefinition 模型，新增 is_boss、boss_rank（legendary/mythic）、phase_count、special_skills_jsonb、enrage_threshold、reward_jsonb 字段
2. CHECK 约束：boss_rank 合法值（legendary/mythic）、phase_count >= 1、enrage_threshold > 0
3. 索引：(is_boss, region_key)

### 步骤 2：world-service 新增Boss API

**目标**：新增Boss专属API端点。

**变更文件**：
- `services/world/app/api/routes.py` - 修改
- `services/world/app/schemas/world.py` - 修改
- `services/world/app/repositories/monster_repo.py` - 修改

**实现内容**：
1. 玩家 API：区域Boss列表（`GET /api/v1/monsters/bosses`）、Boss详情（`GET /api/v1/monsters/bosses/{monster_key}`）
2. 运营 API：创建Boss（`POST /api/v1/ops/monsters/bosses`）
3. 错误码：BOSS_NOT_FOUND、INVALID_BOSS_RANK
4. 业务指标：world_boss_operations_total

### 步骤 3：generation-service 新增Boss数据适配器

**目标**：创建 BossDataAdapter，将 AI 生成的Boss数据转换为 world-service 兼容格式。

**变更文件**：
- `services/generation/app/core/boss_data_adapter.py` - 新建

**实现内容**：
1. 必需字段：monster_key、name、monster_type=boss、chapter_id、region_key、level、hp、attack、defense、speed、description、behavior_pattern、loot_table、skills、is_boss=true、boss_rank、phase_count、special_skills、enrage_threshold、reward
2. 完整度验证（0.95 门槛）
3. 默认值填充
4. Key 规范化

### 步骤 4：generation-service 扩展质量评分器

**目标**：新增 score_boss 方法。

**变更文件**：
- `services/generation/app/core/quality_scorer.py` - 修改

**实现内容**：
1. 必需字段检查（含Boss专属字段）
2. Boss排名合法性（legendary/mythic）
3. 数值区间校验（level 10-60、hp > 0）
4. 阶段数校验（phase_count >= 1）
5. 特殊技能列表校验
6. 奖励配置校验
