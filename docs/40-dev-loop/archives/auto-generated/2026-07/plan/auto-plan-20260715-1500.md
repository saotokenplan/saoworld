## 任务目标与背景

### 目标

对 8 个后端服务的全部 API 端点进行全量审计，更新 API 文档体系（api-overview.md、api-error-codes.md、openapi-v1-draft.yaml），使文档与实际实现完全一致，为灰度发布提供完整的 API 参考基础。

### 背景

- 项目经过 Sprint 1-8 持续迭代，新增了大量 API 端点（社交系统、装备系统、怪物/Boss、异常检测、运营事件等）
- 当前 openapi-v1-draft.yaml 仅覆盖初始 MVP 端点（约 30%），缺失约 120+ 新增端点
- api-overview.md 缺少完整的端点清单，开发者难以快速了解全部 API 表面
- api-error-codes.md 未包含新增服务的错误码（社交、装备、怪物、异常检测等）
- 灰度发布前需要完整的 API 文档作为交付物
