# 状态快照归档入口

> 文档状态：active
> 适用阶段：归档查阅
> 维护要求：持续维护

## 目的

本目录用于归档自动状态快照，帮助读者按时间点回看“某一刻自动化如何判断项目状态”。

## 当前定位

- 本目录是 `docs/40-dev-loop/archives/auto-generated/2026-07/` 下的状态归档子目录。
- 这些快照用于审计和回溯，不替代 `docs/00-governance/project-status.md` 的项目级主状态页。
- 若快照正文仍保留旧路径或旧阶段说法，应按“生成当时的历史记录”理解。

## 使用建议

1. 需要追时间点状态变化时，进入本目录。
2. 需要累计判断与近期摘要时，优先查看 `docs/40-dev-loop/auto-progress-log.md`。
3. 需要当前正式状态结论时，查看 `docs/00-governance/project-status.md`。
