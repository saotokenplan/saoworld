## 三、发现的性能问题汇总

### P0 - 阻塞性问题（必须立即修复）
1. **APIManager 同步阻塞请求**：`_make_request()` 使用 while 循环阻塞等待响应
2. **区域数据重复读取**：`_find_region_data()` 每次调用都重新打开文件解析 JSON
3. **频繁进度轮询**：`_poll_vote_progress()` 固定 10 秒间隔，无动态调整

### P1 - 重要优化（建议尽快实施）
4. **HTTP 请求节点重复创建**：每次请求创建新的 HTTPRequest 节点，无连接池
5. **声望计算复杂**：`calculate_reputation_level()` 和 `get_reputation_progress()` 有重复排序逻辑
6. **场景预加载**：所有场景在启动时预加载，增加启动时间

### P2 - 常规优化（可后续迭代）
7. **缓存过期机制缺失**：`clear_cache()` 只能手动调用
8. **玩家位置查找**：使用 `get_nodes_in_group()` 遍历场景树
9. **资源生命周期管理缺失**：无引用计数和自动卸载
