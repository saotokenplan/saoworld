## 任务目标与背景

### 目标

验证项目首期内容包灰度发布的完整端到端流程，确保：
1. 内容包从 `game/data/` 读取并打包正确
2. 灰度发布范围配置生效
3. 玩家可见性判断逻辑正确
4. 全量发布和回滚流程可用
5. 项目具备真正的灰度发布条件

### 背景

项目当前阶段为"灰度发布就绪"，所有 22 项"下一阶段建议"均已完成，8 个后端服务共 375 个测试用例全部通过。但 seed_initial_packages.py 脚本仅在代码层面验证通过，尚未在真实环境执行完整的内容包创建和发布流程。

本次任务将验证完整的灰度发布流程：
1. 创建首期区域内容包（铁卫城周边、灰谷废墟）
2. 配置灰度范围
3. 执行灰度发布
4. 验证玩家可见性
5. 验证全量发布和回滚流程
