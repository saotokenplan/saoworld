## 任务目标与背景

**目标**：修复 agents 模块从根目录运行 pytest 时的模块命名冲突问题，确保 `cd tools/agents && pytest` 能正确收集并运行全部 226 个测试用例。

**背景**：
- 9 个 agent 模块各自有 `input_schemas.py`、`output_schemas.py`、`error_handler.py` 文件，包含该 agent 特有的数据结构定义
- 每个 agent 的测试文件使用 `sys.path.insert(0, parent_dir)` 加绝对导入（如 `from input_schemas import ...`）
- 当从 `tools/agents/` 根目录运行 pytest 时，Python 模块缓存导致后加载的 agent 找到错误的模块
- 具体表现：product_agent、system_designer_agent、qa_agent、world_agent 4 个 agent 的测试收集失败
- 每个 agent 单独运行测试都能通过（共 226 个），但根目录整体运行时 4 个 agent 无法收集

**优先级**：P0（阻塞 CI 中 agents 模块的整体测试执行）
