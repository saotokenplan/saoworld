## 任务目标与背景

### 为什么要做这件事

Sprint 1 P0 项（玩家移动、世界地图、NPC对话、任务系统、战斗系统、玩家存档）已全部完成，项目进入 Sprint 2 AI 生成接入阶段。当前 generation-service 仅实现了生成请求管理和世界骨架校验，但缺少实际的 AI 内容生成能力：

1. **模板管理缺失**：没有模板加载、匹配和版本管理机制，无法根据投票结果和世界骨架选择合适的生成模板
2. **异步生成任务缺失**：`services/generation/app/tasks/` 目录仅包含空的 `__init__.py`，没有实际的 AI 内容生成异步任务
3. **质量评分缺失**：生成的内容没有质量评估机制，无法判断内容是否满足上线标准（质量评分 < 0.75 应直接废弃）

根据规范要求，长任务（AI生成）必须通过 Celery 异步执行，禁止在 Web 进程中同步处理。因此，实现 generation-service 的 AI 内容生成能力是 Sprint 2 的核心优先级。

### 目标

实现 generation-service 的完整 AI 内容生成能力，包括：
1. 模板管理模块（模板加载、匹配、版本管理）
2. 内容生成 Celery 异步任务（支持 NPC、任务、区域内容生成）
3. 质量评分模块（基于规则的内容质量评估）
4. API 路由更新（支持异步生成触发）
5. 完整测试覆盖

## 具体执行步骤

### 步骤 1：模板管理模块实现

- 创建 `app/core/template_manager.py`：模板加载器、模板匹配器、模板版本管理
- 创建模板目录结构和示例模板（NPC、任务、区域）
- 实现模板匹配逻辑（基于 target_type、region_id、chapter_id）

### 步骤 2：内容生成 Celery 异步任务实现

- 创建 `app/tasks/content_generation.py`：Celery 任务定义
- 实现 `generate_content_task` 异步任务（处理单个生成请求）
- 实现状态更新逻辑（pending → processing → succeeded/failed）
- 实现生成对象落库逻辑

### 步骤 3：质量评分模块实现

- 创建 `app/core/quality_scorer.py`：质量评分器
- 实现质量评分算法（基于长度、格式完整性、关键词密度等指标）
- 设置质量阈值（< 0.75 标记为失败）

### 步骤 4：API 路由更新

- 更新 `app/api/routes.py`：添加异步生成触发端点
- 更新创建生成请求逻辑：创建请求后自动触发 Celery 任务

### 步骤 5：测试编写

- 创建 `tests/test_template_manager.py`：模板管理测试
- 创建 `tests/test_content_generation.py`：生成任务测试
- 创建 `tests/test_quality_scorer.py`：质量评分测试
