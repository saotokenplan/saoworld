## 任务目标与背景

### 为什么要做这件事

Sprint 1 P0 项（S1-01 至 S1-11）已全部完成，核心玩法链路（探索 + 对话 + 任务 + 战斗 + 存档）已完整闭环。项目进入 Sprint 2 AI 生成接入阶段。

当前 generation-service 已具备：
- 模板管理模块（TemplateManager，auto-20260710-0900 完成）
- 质量评分模块（QualityScorer，auto-20260710-0900 完成）
- 内容生成异步任务（process_generation_request，使用模拟数据）
- 事件处理器（投票结果触发内容生成）

但缺少 **真实的 LLM 服务接入**：
- 内容生成使用硬编码模拟数据，无法生成真实游戏内容
- 无 LLM API 调用能力，无法与 OpenAI/Claude/本地模型通信
- 缺少 LLM 配置（API Key、模型选择、Token 限制等）

根据需求迭代计划 Sprint 2 S2-01「LLM服务接入」为 P0 优先级，验收标准：「可通过API调用生成NPC描述、任务文本」。

### 目标

实现 generation-service 的真实 LLM 服务接入能力，包括：
1. LLM 服务适配器模块（支持 OpenAI API 和本地模型）
2. 基于 LLM 的内容生成器（NPC、任务、区域描述生成）
3. LLM 配置管理（API Key、模型、Token 限制、超时）
4. Workers 异步任务集成真实生成
5. 完整测试覆盖

## 具体执行步骤

### 步骤 1：LLM 服务适配器模块实现

- 创建 `app/core/llm_adapter.py`：LLM 服务适配器接口
- 实现 `LLMAdapter` 抽象基类（统一调用接口）
- 实现 `OpenAIAdapter`（支持 OpenAI API）
- 实现 `MockLLMAdapter`（测试环境使用）
- 实现错误处理（API 调用失败、Token 超限、超时）

### 步骤 2：基于 LLM 的内容生成器实现

- 创建 `app/core/content_generator.py`：内容生成器
- 实现 `generate_npc_description()`：NPC 描述生成
- 实现 `generate_quest_text()`：任务文本生成
- 实现 `generate_region_description()`：区域描述生成
- 集成模板管理（使用模板渲染 Prompt）
- 集成质量评分（生成后自动评分）

### 步骤 3：配置管理更新

- 更新 `app/core/config.py`：添加 LLM 配置项
  - `llm_provider`（openai/mock）
  - `llm_api_key`
  - `llm_model`（gpt-4o-mini/gpt-4o）
  - `llm_max_tokens`
  - `llm_temperature`
  - `llm_timeout`
- 更新 `.env.example`：添加 LLM 配置示例

### 步骤 4：Workers 异步任务集成

- 更新 `workers/tasks/content_generation.py`：
  - 替换模拟数据生成为真实 LLM 调用
  - 添加 LLM 服务客户端
  - 处理 LLM 调用失败重试

### 步骤 5：测试编写

- 创建 `tests/test_llm_adapter.py`：LLM 适配器测试
- 创建 `tests/test_content_generator.py`：内容生成器测试
- 使用 MockLLMAdapter 进行单元测试
- 测试 LLM 调用失败处理
