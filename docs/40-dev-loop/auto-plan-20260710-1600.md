## 任务目标与背景

### 目标

实现生成成本控制能力，包括 Token 用量统计、成本估算、超阈值告警和预算限制，确保 AI 生成内容的成本可控。

### 背景

Sprint 2 AI 生成接入阶段已完成：
- S2-01 LLM 服务接入 ✅
- S2-02 NPC 生成模板 ✅
- S2-03 任务生成模板 ✅
- S2-04 聚落描述生成 ✅
- S2-05 生成质量评分 ✅
- S2-06 投票结果→生成参数映射 ✅
- S2-07 端到端闭环验证 ✅

仅剩 S2-08 生成成本控制进行中。

AI 内容生成会产生持续的 API 调用成本（Token 消耗），需要建立成本监控和控制机制，避免成本失控。

### 验收标准

- 每次生成请求记录 Token 用量和估算成本
- 支持按时间段查询 Token 使用量
- 支持配置每日/每月 Token 预算
- 超阈值时触发告警
- 超预算时自动限制或暂停生成

## 具体执行步骤

### 步骤 1：扩展配置支持成本控制参数

- 在 `config.py` 添加成本控制配置项（每日预算、每月预算、告警阈值、模型定价）
- 更新 `.env.example` 添加新配置项

### 步骤 2：创建成本计算器模块

- 创建 `app/core/cost_calculator.py`
- 实现 Token 用量统计
- 实现成本估算（基于模型定价）
- 实现预算检查

### 步骤 3：扩展 LLMAdapter 记录 Token 用量

- 更新 LLMResponse 添加成本字段
- 更新 MockLLMAdapter 和 OpenAIAdapter 返回用量信息
- 添加 Token 用量日志记录

### 步骤 4：扩展数据库模型支持成本记录

- 在 `models.py` 添加 Token 用量字段（prompt_tokens、completion_tokens、total_tokens、cost_usd）
- 创建 Alembic 迁移脚本

### 步骤 5：创建成本监控 API

- 在 `routes.py` 添加成本统计查询端点
- 在 `schemas.py` 添加成本相关请求/响应模型
- 在 `repositories/generation_repo.py` 添加成本统计查询方法

### 步骤 6：实现预算告警机制

- 创建 `app/core/budget_alert.py` 预算告警模块
- 实现超阈值检测
- 实现告警日志记录和事件发布

### 步骤 7：编写测试用例

- 成本计算器测试
- 预算检查测试
- 成本统计 API 测试
- 告警机制测试
