## 任务目标与背景

Sprint 3 S3-01「贡献度系统」和 S3-02「投票资格门槛」已完成。S3-03 是 Sprint 3 的下一个 P0 任务，目标是在 player-service 中实现成就系统：

1. 成就定义（achievement_definitions）：成就的元数据（ID、名称、描述、图标、稀有度、奖励）
2. 玩家成就（player_achievements）：玩家已解锁的成就记录
3. 成就解锁检查：在关键操作（完成任务、获得声望、投票参与等）时检查并解锁成就
4. 成就 API：玩家查询成就列表、成就详情、已解锁成就
5. 运营 API：创建成就定义、手动解锁成就

本任务完成后，玩家成长系统将具备"成就反馈"核心能力，为后续个人中心和玩家成长体系奠定基础。

## 具体执行步骤

### 步骤 1：实现成就数据模型

- 在 `services/player/app/domain/models.py` 中新增：
  - `AchievementDefinition`：成就定义表（achievement_key, name, description, icon, rarity, category, reward_jsonb, condition_jsonb, points, created_at, updated_at）
  - `PlayerAchievement`：玩家成就表（player_achievement_id, player_id, achievement_key, unlocked_at, reward_claimed, claimed_at）
- 添加 CHECK 约束和索引
- 创建 Alembic 迁移脚本

### 步骤 2：实现成就仓储层

- 在 `services/player/app/repositories/` 下新增 `achievement_repo.py`
- `AchievementDefinitionRepository`：
  - `list_definitions()`：获取成就定义列表
  - `get_definition()`：获取单个成就定义
  - `create_definition()`：创建成就定义
- `PlayerAchievementRepository`：
  - `get_player_achievements()`：获取玩家已解锁成就
  - `get_player_achievement()`：获取玩家单个成就
  - `unlock_achievement()`：解锁成就（幂等，已解锁则返回现有记录）
  - `claim_reward()`：领取成就奖励

### 步骤 3：实现成就 Pydantic Schemas

- 在 `services/player/app/schemas/player.py` 中新增：
  - `AchievementRarity` 枚举（common, uncommon, rare, epic, legendary）
  - `AchievementCategory` 枚举（quest, exploration, combat, reputation, vote, social, collection）
  - `AchievementDefinitionResponse`：成就定义响应
  - `PlayerAchievementResponse`：玩家成就响应
  - `AchievementListResponse`：成就列表（含已解锁状态）
  - `CreateAchievementRequest`：创建成就请求
  - `UnlockAchievementRequest`：手动解锁请求
  - `ClaimAchievementRewardRequest`：领取奖励请求

### 步骤 4：实现成就 API 端点

- 玩家 API（`router`）：
  - `GET /player/achievements`：获取成就列表（含解锁状态）
  - `GET /player/achievements/{achievement_key}`：获取成就详情
- 运营 API（`ops_router`）：
  - `POST /ops/achievements`：创建成就定义
  - `GET /ops/achievements`：获取成就定义列表
  - `GET /ops/players/{player_id}/achievements`：获取玩家成就
  - `POST /ops/players/{player_id}/achievements/{achievement_key}/unlock`：手动解锁成就
