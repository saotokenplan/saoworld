## 任务目标与背景

Sprint 3 S3-01「贡献度系统」、S3-02「投票资格门槛」、S3-03「成就系统」已完成。S3-04 是 Sprint 3 的下一个 P0 任务，目标是在 player-service 和 Godot 客户端实现个人中心功能：

1. **player-service API 扩展**：
   - 聚合玩家完整信息（基本信息、贡献度、声望、成就统计）
   - 投票记录查询（历史投票、投票权重）
   - 贡献度流水查询
   - 声望汇总查询
   - 成就统计查询

2. **Godot 客户端个人中心界面**：
   - 玩家信息展示（等级、经验、贡献度）
   - 投票记录标签页（历史投票列表、投票结果）
   - 贡献度标签页（当前贡献度、流水记录）
   - 声望标签页（各区域声望等级、进度）
   - 成就标签页（已解锁成就、成就分类）

本任务完成后，玩家将拥有完整的个人信息中心，为后续社交系统和个人展示奠定基础。

## 具体执行步骤

### 步骤 1：实现 player-service 个人中心 API

- 在 `services/player/app/api/routes.py` 新增玩家信息聚合接口：
  - `GET /api/v1/player/profile`：返回玩家完整信息（基本信息+贡献度+声望+成就统计）
- 扩展现有接口支持更丰富的查询：
  - `GET /api/v1/player/contribution`：已存在，返回贡献度与流水
  - `GET /api/v1/player/reputation`：已存在，返回声望汇总
  - `GET /api/v1/player/achievements`：已存在，返回成就列表
- 新增 Schema：
  - `PlayerProfileResponse`：聚合玩家信息响应

### 步骤 2：实现 vote-service 投票历史查询 API

- 在 `services/vote/app/api/routes.py` 扩展历史查询接口：
  - `GET /api/v1/votes/history`：已存在，返回玩家历史投票记录
  - 扩展响应包含：投票周期信息、候选项、投票权重、最终结果

### 步骤 3：实现 Godot 客户端 PlayerManager 扩展

- 在 `game/scripts/autoload/player_manager.gd` 新增方法：
  - `fetch_player_profile()`：调用 player-service `/api/v1/player/profile`

  - 新增信号：`profile_loaded`、`vote_history_loaded`
