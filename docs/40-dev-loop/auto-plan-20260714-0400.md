## 任务目标与背景

### 目标

实现投票结果可视化功能，将投票结果以图表形式展示，提升玩家对投票结果的理解和感知。

### 背景

当前投票结果仅以列表形式展示各候选项的票数和百分比，缺乏直观的可视化展示。图表可视化能够：
- 提升玩家对投票结果的直观理解
- 增强投票参与感和结果感知
- 为后续投票复盘报告奠定基础
- 提升整体用户体验

### 需求来源

Sprint 4 S4-04「投票结果可视化」，项目每日进展报告（2026-07-13）中标记为"未开始"。

## 具体执行步骤

### 步骤 1：vote-service 扩展投票结果图表数据接口

**目标**：提供投票结果的图表数据格式，支持多种图表类型

**变更文件**：
- `services/vote/app/api/routes.py` - 新增图表数据路由
- `services/vote/app/schemas/vote.py` - 新增图表数据响应 Schema
- `services/vote/app/repositories/vote_repo.py` - 新增图表数据查询方法

**实现内容**：
1. 新增 `GET /api/v1/votes/history/{vote_cycle_id}/chart-data` 接口
2. 返回图表数据格式：
   - 饼图数据：各候选项名称、票数、百分比、颜色
   - 柱状图数据：各候选项名称、票数、颜色
3. 支持通过 `chart_type` 参数选择图表类型（pie/bar）

### 步骤 2：客户端 VoteResultPanel 实现饼图可视化

**目标**：投票结果面板展示饼图，直观显示各候选项占比

**变更文件**：
- `game/scenes/ui/voting/vote_result_panel.tscn` - 新增饼图绘制节点
- `game/scripts/ui/voting/vote_result_panel.gd` - 新增饼图绘制逻辑

**实现内容**：
1. 使用 Godot 的 `draw_arc` 和 `draw_polygon` 绘制饼图扇形
2. 每个扇形代表一个候选项，大小对应票数百分比
3. 显示候选项名称和百分比标签
4. 支持鼠标悬停显示详情

### 步骤 3：客户端 VoteResultPanel 实现柱状图可视化

**目标**：投票结果面板支持切换显示柱状图

**变更文件**：
- `game/scenes/ui/voting/vote_result_panel.tscn` - 新增柱状图绘制节点
- `game/scripts/ui/voting/vote_result_panel.gd` - 新增柱状图绘制逻辑

**实现内容**：
1. 使用 Godot 的 `draw_rect` 绘制柱状图
2. 每个柱子代表一个候选项，高度对应票数
3. 显示候选项名称和票数标签
4. 支持鼠标悬停显示详情

### 步骤 4：客户端 VoteManager 扩展图表数据获取方法

**目标**：VoteManager 提供图表数据获取方法

**变更文件**：
- `game/scripts/autoload/vote_manager.gd` - 新增图表数据获取方法

**实现内容**：
1. 新增 `fetch_vote_result_chart_data(vote_cycle_id: String, chart_type: String)` 方法
2. 新增 `chart_data_loaded` 信号
3. 支持缓存图表数据

- `game/tests/test_vote_result_panel.gd` - 新增饼图/柱状图绘制测试
