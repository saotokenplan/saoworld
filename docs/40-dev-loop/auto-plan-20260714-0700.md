## 审计发现与修复

### 严重问题（Critical）
1. **JWT 密钥硬编码** - 修复：移除所有服务的 `change-me-in-production` 默认值，强制环境变量配置

### 中等问题（Medium）
2. **CORS 配置过宽** - 修复：替换 `allow_origins=["*"]` 为白名单列表，限制方法和请求头
3. **网关缺少 Scope 校验** - 修复：添加 PATH_SCOPE_RULES 路径-权限映射和 has_required_scope 校验
4. **投票权重溢出风险** - 修复：添加最终权重不超过 10.0 的校验
