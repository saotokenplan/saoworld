## 具体执行步骤

### 步骤 1：player-service 数据模型（friendships 表）

**目标**：定义好友关系数据模型。

**变更文件**：
- `services/player/app/domain/models.py` - 新增 Friendship 模型

**实现内容**：
1. 新增 `friendships` 表，包含字段：
   - `friendship_id`：UUID 主键
   - `player_id`：发起者 UUID（外键 → players）
   - `friend_id`：目标玩家 UUID（外键 → players）
   - `status`：好友请求状态（pending/accepted/rejected/blocked）
   - `created_at`：创建时间
   - `updated_at`：更新时间
2. CHECK 约束：status IN ('pending', 'accepted', 'rejected', 'blocked')
3. 唯一索引：(player_id, friend_id) 防止重复请求
4. 复合索引：(friend_id, status) 支持查询收到的好友请求

### 步骤 2：FriendRepository 仓储层实现

**目标**：实现好友关系的数据访问逻辑。

**变更文件**：
- `services/player/app/repositories/friend_repo.py` - 新建文件

**实现内容**：
1. `send_friend_request` - 发送好友请求（幂等：已有 pending 请求则返回原记录）
2. `accept_friend_request` - 接受好友请求（状态迁移 pending → accepted）
3. `reject_friend_request` - 拒绝好友请求（状态迁移 pending → rejected）
4. `delete_friend` - 删除好友（双向删除）
5. `block_friend` - 拉黑好友（状态 → blocked）
6. `get_friends` - 获取好友列表（分页）
7. `get_pending_requests` - 获取待处理的好友请求
8. `get_friendship` - 查询两人间的好友关系
9. `are_friends` - 判断两人是否为好友
10. `get_friend_count` - 获取好友数量

### 步骤 3：API 接口实现

**目标**：实现好友系统的 RESTful API。

**变更文件**：
- `services/player/app/api/routes.py` - 新增好友相关路由
- `services/player/app/schemas/player.py` - 新增好友相关 Schema
- `services/player/app/core/deps.py` - 新增好友相关 Scope
- `services/player/app/schemas/auth.py` - 新增 FRIENDS_READ/FRIENDS_WRITE Scope
- `services/player/app/core/errors.py` - 新增好友相关错误码
- `services/player/app/core/metrics.py` - 新增好友相关指标
- `services/player/app/repositories/audit_repo.py` - 新增好友审计动作

**API 接口**：
- `POST /api/v1/player/friends/request` - 发送好友请求（Scope: friends:write）
- `POST /api/v1/player/friends/accept` - 接受好友请求（Scope: friends:write）
- `POST /api/v1/player/friends/reject` - 拒绝好友请求（Scope: friends:write）
- `DELETE /api/v1/player/friends/{friend_id}` - 删除好友（Scope: friends:write）
- `GET /api/v1/player/friends` - 获取好友列表（Scope: friends:read）
- `GET /api/v1/player/friends/requests` - 获取待处理请求（Scope: friends:read）
- `GET /api/v1/player/friends/{friend_id}/status` - 查询好友关系状态（Scope: friends:read）

**错误码**：
- `FRIEND_REQUEST_ALREADY_SENT` - 好友请求已发送
- `FRIEND_REQUEST_NOT_FOUND` - 好友请求不存在
- `FRIEND_REQUEST_NOT_PENDING` - 好友请求非待处理状态
- `ALREADY_FRIENDS` - 已经是好友
- `CANNOT_FRIEND_SELF` - 不能添加自己为好友
- `FRIEND_NOT_FOUND` - 好友关系不存在
- `FRIEND_BLOCKED` - 已被对方拉黑

**业务指标**：
- `friend_requests_sent_total` - 好友请求发送数
- `friend_requests_accepted_total` - 好友请求接受数
