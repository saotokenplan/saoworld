## 任务目标与背景

### 目标

实现装备系统基础能力，在 world-service 中新增装备定义表，在 player-service 中新增玩家装备栏和装备穿戴/卸下功能，为 Sprint 7 内容扩展阶段奠定装备系统基础。

### 背景

Sprint 6 运营工具阶段 S6-01（运营后台统一API）、S6-06（运营事件配置）、S6-07（异常检测告警）已完成，项目具备首期内容包灰度发布条件。Sprint 7 S7-02「装备系统」作为 P0 项，需要实现装备定义、装备获取、装备穿戴、装备属性等基础能力，为后续装备生成模板（S7-06）和 Boss 战掉落（S7-04）奠定基础。

### 需求来源

`docs/10-requirements/需求迭代计划.md` Sprint 7 S7-02「装备系统」，验收标准：装备获取、装备属性、装备强化。

## 具体执行步骤

### 步骤 1：world-service 新增装备定义数据模型

**目标**：在 world-service 中新增装备定义表。

**变更文件**：
- `services/world/app/domain/models.py` - 新增 ItemDefinition 模型

**实现内容**：
1. 新增 `item_definitions` 表，字段包括：
   - item_id（UUID 主键）
   - item_key（物品唯一标识，唯一索引）
   - item_type（物品类型：weapon/armor/accessory/consumable/material）
   - item_slot（装备槽位：head/chest/legs/feet/weapon/off_hand/ring/necklace，仅装备类型有值）
   - name（物品名称）
   - description（物品描述）
   - rarity（稀有度：common/uncommon/rare/epic/legendary）
   - chapter_id（所属章节）
   - level_requirement（等级要求）
   - stats_jsonb（属性 JSONB：攻击、防御、生命、暴击等）
   - effects_jsonb（特效 JSONB：技能、被动效果等）
   - sell_price（出售价格）
   - stackable（是否可堆叠）
   - schema_version（schema 版本，默认 1）
   - created_at / updated_at
2. CHECK 约束：item_type、rarity、item_slot 合法值
3. 索引：item_key（唯一）、item_type、rarity、chapter_id

### 步骤 2：world-service 实现装备定义仓储层与 API

**目标**：提供装备定义的 CRUD 和查询接口。

**变更文件**：
- `services/world/app/repositories/world_repo.py` - 新增装备定义相关方法
- `services/world/app/api/routes.py` - 新增装备定义 API 端点
- `services/world/app/schemas/world.py` - 新增装备相关 Schema

**实现内容**：
1. ItemDefinitionRepository 方法：
   - get_item_by_key：根据 item_key 查询
   - get_item_by_id：根据 ID 查询
   - list_items：分页列表（按类型、稀有度、章节过滤）
   - create_item：创建装备定义
   - update_item：更新装备定义
   - delete_item：删除装备定义
2. API 端点：
   - GET /world/items - 玩家侧：装备列表（分页，过滤）
   - GET /world/items/{item_key} - 玩家侧：装备详情
   - POST /ops/items - 运营侧：创建设备定义
   - PUT /ops/items/{item_id} - 运营侧：更新装备定义
   - DELETE /ops/items/{item_id} - 运营侧：删除装备定义

### 步骤 3：player-service 新增玩家装备栏数据模型

**目标**：在 player-service 中新增玩家装备栏表。

**变更文件**：
- `services/player/app/domain/models.py` - 新增 PlayerEquipment 模型

**实现内容**：
1. 新增 `player_equipment` 表，字段包括：
   - equipment_id（UUID 主键）
   - player_id（玩家 ID，外键）
   - slot（装备槽位：head/chest/legs/feet/weapon/off_hand/ring/necklace）
   - item_key（装备 item_key）
   - item_instance_id（物品实例 ID，用于区分不同实例的强化等级等）
   - level（强化等级，默认 0）
   - stats_jsonb（当前属性快照 JSONB）
   - equipped_at（装备时间）
   - created_at / updated_at
2. CHECK 约束：slot 合法值
3. 唯一约束：UNIQUE (player_id, slot) - 每个槽位只能装备一件
4. 索引：player_id、item_key

### 步骤 4：player-service 实现装备系统仓储层

**目标**：实现装备穿戴、卸下、属性计算等核心逻辑。

**变更文件**：
- `services/player/app/repositories/equipment_repo.py` - 新建文件

**实现内容**：
1. EquipmentRepository 类
2. 方法：
   - get_equipment：获取玩家所有已装备物品
   - get_equipment_by_slot：获取指定槽位的装备
   - equip_item：装备物品（从背包移动到装备栏）
   - unequip_item：卸下装备（从装备栏移回背包）
   - get_equipment_stats：计算玩家装备总属性加成
   - can_equip_item：检查是否满足装备条件（等级、职业等）

### 步骤 5：player-service 新增装备系统 API

**目标**：提供玩家装备查询、穿戴、卸下接口。

**变更文件**：
- `services/player/app/api/routes.py` - 新增装备系统端点
- `services/player/app/schemas/player.py` - 新增装备相关 Schema

**实现内容**：
1. API 端点：
   - GET /player/equipment - 获取玩家当前装备
   - POST /player/equipment/equip - 装备物品（从背包装备）
   - POST /player/equipment/unequip - 卸下装备（放回背包）
   - GET /player/equipment/stats - 获取装备总属性加成
2. 集成背包系统：装备时从背包扣除，卸下时加回背包

### 步骤 6：新增错误码、业务指标与审计动作

**目标**：补充装备系统相关的错误码、指标和审计。

**变更文件**：
- `services/world/app/core/errors.py` - 新增装备定义相关错误码
- `services/world/app/core/metrics.py` - 新增业务指标
- `services/world/app/repositories/audit_repo.py` - 新增审计动作常量
- `services/player/app/core/errors.py` - 新增玩家装备相关错误码
- `services/player/app/core/metrics.py` - 新增业务指标
- `services/player/app/repositories/audit_repo.py` - 新增审计动作常量

**实现内容**：
1. world-service 错误码：
   - ITEM_NOT_FOUND（装备定义不存在）
   - ITEM_KEY_EXISTS（item_key 已存在）
   - INVALID_ITEM_TYPE（无效的物品类型）
2. player-service 错误码：
   - EQUIPMENT_SLOT_OCCUPIED（装备槽位已被占用）
   - CANNOT_UNEQUIP_EMPTY_SLOT（槽位为空无法卸下）
   - INSUFFICIENT_ITEM_LEVEL（等级不足无法装备）
   - ITEM_NOT_EQUIPPABLE（物品不可装备）
3. 业务指标：
   - items_created_total（装备定义创建数）
   - equipment_equipped_total（装备穿戴次数）
   - equipment_unequipped_total（装备卸下次数）
4. 审计动作：
   - ACTION_ITEM_CREATE / ACTION_ITEM_UPDATE / ACTION_ITEM_DELETE
   - ACTION_EQUIP_ITEM / ACTION_UNEQUIP_ITEM
   - RESOURCE_ITEM_DEFINITION / RESOURCE_PLAYER_EQUIPMENT
