## 任务目标与背景

### 目标

完成客户端性能优化的第三阶段（SaveManager 存档优化）和第四阶段（PlayerManager 优化），进一步提升客户端响应流畅度和加载速度。

### 背景

根据 S8-01 性能分析报告，客户端存在以下性能问题需要优化：

**第三阶段 - SaveManager 优化**：
- P1：存档文件同步读写阻塞主线程
- P2：get_save_info 重复读取整个存档文件
- P2：缺少增量保存机制

**第四阶段 - PlayerManager 优化**：
- P1：refresh_all() 串行调用多个 API
- P2：声望计算使用自定义排序，每次调用都重新排序
- P2：玩家任务/区域查询使用线性搜索，无索引

### 性能目标

- 存档加载时间 < 100ms
- 声望计算速度提升 50%
- 任务/区域查询从 O(n) 优化为 O(1)
