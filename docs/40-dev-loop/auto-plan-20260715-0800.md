## 任务目标与背景

### 目标

为 S8-01 客户端性能优化第三阶段（SaveManager 存档优化）和第四阶段（PlayerManager 优化）补充缺失的 GUT 测试用例，并修复因索引化改造导致的现有测试断裂问题。

### 背景

S8-01 第三、四阶段（auto-20260715-0700）完成了以下优化：
- SaveManager 异步存档（Thread）、存档信息缓存（TTL 60s）、缓存失效机制
- PlayerManager 任务/区域索引字典（O(1) 查询）、预排序声望级别列表、并行 API 请求

但该轮执行的计划文档中以下步骤未完成：
- [ ] 更新 SaveManager 相关测试用例
- [ ] 更新 PlayerManager 相关测试用例
- [ ] 运行客户端 GUT 测试验证优化效果

更严重的是，PlayerManager 的索引化改造引入了**潜在测试断裂**：
- `get_player_quest_by_id()` 改为从 `quest_index` 读取，但 `quest_index` 仅在 `_handle_player_quests_success()` → `_update_quest_index()` 中填充
- 现有测试 `test_get_player_quest_by_id`、`test_is_quest_active`、`test_is_quest_completed` 直接设置 `player_quests` 而未填充 `quest_index`，会导致查询返回空字典
- `test_is_region_unlocked` 同样受 `region_index` 未填充影响
- 由于沙箱环境未安装 Godot 引擎，GUT 测试未实际运行，该断裂未被及时发现

本任务闭合测试验收缺口，遵循 `.trae/rules/41-testing.md` 中"修改游戏逻辑时必须同步更新相关测试用例"的要求。
