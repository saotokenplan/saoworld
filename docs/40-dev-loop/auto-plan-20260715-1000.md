## 任务目标与背景

### 目标

补全灰度发布前验证中遗留的 mypy 类型检查缺口。上一轮全量验证（auto-20260715-0900）中，mypy 类型检查因「环境限制，暂跳过」未执行。本任务安装全部 8 个后端服务的 dev 依赖，运行 mypy 收集并修复所有类型错误，使 mypy 类型检查门禁真正生效。

### 背景

- 项目处于灰度发布就绪状态，所有 913 个后端测试通过
- 上一轮验证中 mypy 类型检查被标记为「环境限制，暂跳过」
- `10-python-backend.md` 规范要求 mypy >= 1.10 作为类型检查门禁
- CI 配置中 mypy 已作为阻塞门禁（移除了 `|| true` 绕过），但本地验证不完整
- 需要确保类型安全，为灰度发布提供额外质量保障
