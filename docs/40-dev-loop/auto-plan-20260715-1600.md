## 审计范围与内容

### 审计服务清单

| 服务 | 审计内容 | 优先级 |
|------|---------|--------|
| world-service | JWT鉴权、输入校验、权限边界、CORS、密钥安全 | 高 |
| generation-service | JWT鉴权、输入校验、权限边界、CORS、密钥安全、LLM API密钥 | 高 |
| review-service | JWT鉴权、输入校验、权限边界、CORS、密钥安全 | 中 |
| ops-service | JWT鉴权、输入校验、权限边界、CORS、密钥安全、跨服务调用 | 高 |

### 审计维度

1. **鉴权机制审计**
   - JWT token 验证逻辑
   - Scope 权限校验完整性
   - 角色权限边界正确性

2. **输入校验审计**
   - API 输入参数校验
   - SQL 注入防护
   - XSS 防护
   - 字符串长度限制
   - 数字范围限制

3. **权限边界审计**
   - 玩家接口与运营接口隔离
   - 敏感操作审计日志记录
   - 数据访问权限控制

4. **CORS 安全审计**
   - 是否使用通配符允许来源
   - 允许的 HTTP 方法限制
   - 允许的请求头限制

5. **密钥安全审计**
   - JWT 密钥是否硬编码
   - 是否强制环境变量配置
   - 默认值检测与报错

6. **敏感数据审计**
   - API Key、密钥等敏感信息泄露风险
   - 日志中是否输出敏感数据
