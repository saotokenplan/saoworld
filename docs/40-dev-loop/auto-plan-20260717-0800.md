## 任务目标与背景

### 目标
完成 M2 里程碑社交系统扩展剩余功能，包括：
1. 公会战系统（宣战、接受、参与、计分、完成）
2. 好友协作任务系统（创建、接受、进度更新、完成）

### 背景
根据项目状态文档，M2 里程碑中第三章区域开发（M2-01）和公会任务（M2-02）及经济系统（M2-03）已完成。社交系统扩展中公会战和好友协作任务尚未实现，是 M2 里程碑剩余的核心功能。

公会战系统为公会提供竞争对抗玩法，增强公会凝聚力和长期参与感；好友协作任务为好友间提供协作完成目标的机制，增强社交粘性。

## 具体执行步骤

### 步骤 1：公会战系统实现（player-service）

#### 1.1 数据模型定义
- 创建 `guild_wars` 表（战争记录，含宣战/接受/进行/完成/取消5种状态，领土/资源/荣誉3种类型）
- 创建 `guild_war_participants` 表（参战成员记录，含击杀/死亡/贡献分数，UNIQUE(war_id, player_id)）

#### 1.2 仓储层实现
- GuildWarRepository：15个方法（宣战、接受、取消、开始、完成、查询、加入、击杀记录、记分板等）

#### 1.3 API 端点（9个）
- POST /player/guild/wars（宣战）
- POST /player/guild/wars/{war_id}/accept（接受宣战）
- POST /player/guild/wars/{war_id}/cancel（取消战争）
- GET /player/guild/wars/active（进行中战争）
- GET /player/guild/wars/history（战争历史）
- GET /player/guild/wars/{war_id}（战争详情）
- POST /player/guild/wars/{war_id}/join（加入战争）
- GET /player/guild/wars/{war_id}/scoreboard（记分板）
- POST /player/guild/wars/{war_id}/complete（完成战争）

#### 1.4 错误码（8个）
- GUILD_WAR_NOT_FOUND、GUILD_WAR_NOT_DECLARED、CANNOT_DECLARE_WAR_ON_SELF 等

### 步骤 2：好友协作任务系统实现（player-service）

#### 2.1 数据模型定义
- 创建 `friend_collab_quests` 表（协作任务，含5种类型和5种状态，JSONB目标/进度/奖励）

#### 2.2 仓储层实现
- FriendCollabQuestRepository：12个方法（创建、接受、拒绝、进度更新、完成、过期处理等）

#### 2.3 API 端点（8个）
- POST /player/friend/collab-quests（创建协作任务）
- POST /player/friend/collab-quests/{quest_id}/accept（接受邀请）
- POST /player/friend/collab-quests/{quest_id}/reject（拒绝邀请）
- POST /player/friend/collab-quests/{quest_id}/progress（更新进度）
- POST /player/friend/collab-quests/{quest_id}/complete（完成任务）
- GET /player/friend/collab-quests/active（进行中任务）
- GET /player/friend/collab-quests/pending（待处理邀请）
- GET /player/friend/collab-quests/history（任务历史）

#### 2.4 错误码（7个）
- COLLAB_QUEST_NOT_FOUND、COLLAB_QUEST_NOT_PENDING、NOT_FRIENDS_FOR_COLLAB 等
