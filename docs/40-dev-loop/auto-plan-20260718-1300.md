> 任务标识：auto-20260718-1300
> 创建时间：2026-07-18 13:00
> 工作分支：auto/auto-20260718-1300
> 任务状态：已完成

## 任务目标与背景

### 目标
完成客户端经济系统 UI，包括钱包面板、玩家间交易面板和拍卖行面板，为玩家提供完整的经济交互能力。

具体包括：
1. 创建 `WalletManager` 自动加载单例，封装钱包 API
2. 创建 `TradeManager` 自动加载单例，封装交易和拍卖行 API
3. 创建 `WalletPanel` 场景与脚本（金币余额、交易流水）
4. 创建 `TradePanel` 场景与脚本（发起交易、交易列表、接受/拒绝/取消）


5. 创建 `AuctionPanel` 场景与脚本（拍卖行列表、上架、竞拍）
6. 将经济系统面板集成到个人中心
7. 编写 GUT 测试用例

### 背景
M2-03 经济系统后端已完成（auto-20260717-0000），包含钱包、交易和拍卖行三个子系统。但客户端尚无对应 UI，玩家无法在游戏中使用这些功能。本任务参照已有的 Manager 模式（如 GuildManager、FriendManager）和个人中心集成模式（如装备面板），补齐客户端经济系统闭环。

## 具体执行步骤

### 步骤 1：创建 WalletManager 自动加载单例
- 在 `project.godot` 的 `[autoload]` 段新增注册
- 声明必要的信号和状态字段
- 封装钱包余额查询、交易流水获取等 API 方法
- 实现数据缓存和清理机制

### 步骤 2：创建 TradeManager 自动加载单例
- 在 `project.godot` 的 `[autoload]` 段新增注册
- 声明交易和拍卖行相关的信号及状态字段
- 封装交易创建、接受、拒绝、取消和列表查询等方法
- 封装拍卖行上架、竞拍、取消和列表查询等方法
- 实现数据缓存和清理机制

### 步骤 3：创建 WalletPanel 场景与脚本
- 场景文件：`game/scenes/ui/economy/WalletPanel.tscn`
- 脚本文件：`game/scripts/ui/economy/wallet_panel.gd`
- 布局：VBoxContainer 包含金币余额显示、交易流水列表和分页控制
- 信号：`close_pressed`
- 功能：展示当前金币数量和历史交易记录

### 步骤 4：创建 TradePanel 场景与脚本
- 场景文件：`game/scenes/ui/economy/TradePanel.tscn`
- 脚本文件：`game/scripts/ui/economy/trade_panel.gd`
- 布局：TabContainer 包含交易列表和发起交易表单
- 信号：`close_pressed`、`trade_selected(trade_id)`
- 功能：查看交易请求、接受/拒绝/取消交易、向其他玩家发起交易

### 步骤 5：创建 AuctionPanel 场景与脚本
- 场景文件：`game/scenes/ui/economy/AuctionPanel.tscn`
- 脚本文件：`game/scripts/ui/economy/auction_panel.gd`
- 布局：TabContainer 包含拍卖行列表和上架物品表单
- 信号：`close_pressed`、`listing_selected(listing_id)`
- 功能：浏览拍卖行物品、竞拍、上架物品、取消上架

### 步骤 6：集成到个人中心
- 修改 `PersonalCenter.tscn` 新增经济系统标签页
- 调整 `personal_center.gd` 集成 WalletPanel、TradePanel、AuctionPanel
- 建立标签页切换和数据联动机制

### 步骤 7：编写 GUT 测试

- 创建 `test_trade_panel.gd` 测试交易面板功能
- 创建 `test_auction_panel.gd` 测试拍卖行面板功能
