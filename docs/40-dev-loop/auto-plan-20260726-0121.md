## 具体执行步骤（每步可独立验收）

### 步骤 1：M4 新增规则归因 Counter（metrics.py + auto_review_engine.py）
- 在 `services/review/app/core/metrics.py` 新增 `REVIEW_RULE_DECISIONS_TOTAL = Counter("review_rule_decisions_total", ..., labelnames=["rule", "result"])` 与 `record_rule_decision(rule, result)` 助手。
- 在 `auto_review_engine.py` 的 `evaluate` 循环内，对每条规则判定结果调用 `record_rule_decision(rule_name, result or "not_applied")`，异常路径记录 `"error"`。
- **验收**：`test_review_metrics.py` 运行引擎后对 `review_rule_decisions_total{rule,result}` 增量断言。

### 步骤 2：M2 修复 reviews_total 计数 + review_type 标签（metrics.py + routes.py）
- `metrics.py`：`REVIEWS_TOTAL` 标签改为 `["result", "review_type"]`；`record_review_result(result, review_type)` 新增 `review_type` 形参。
- `routes.py`：
  - `approve_review_object` / `reject_review_object`：`record_review_result("approved"/"rejected", "manual")`。
  - `auto_review`：将 `record_review_result(result["auto_result"], "auto")` 移出 `if is_automatic` 块，**对所有终局判定（含 manual_review）统一计数**。
- **验收**：指标按 `review_type` 区分；auto 路径 manual_review 现在也计入分母（修复 M2 失真）。

### 步骤 3：M1 新增审核耗时 Histogram（metrics.py + routes.py）
- `metrics.py`：新增 `REVIEW_DURATION_SECONDS = Histogram("review_duration_seconds", ..., labelnames=["review_type", "object_type"], buckets=[...])` 与 `record_review_duration(review_type, object_type, seconds)` 助手。
- `routes.py`：在审核终结点记录耗时——
  - `auto_review`：`(review.updated_at - review.created_at).total_seconds()`，标签 `("auto", body.object_type)`。
  - `approve_review_object` / `reject_review_object` / `update_review_result`：对每个 `updated_review` 用 `(now_utc - updated_review.created_at).total_seconds()`，标签 `("manual", updated_review.object_type)`。
- **验收**：`record_review_duration` 助手单测断言 Histogram 桶计数增量。
