# 日报入口

> 说明：本目录用于保留逐日进展记录，重点回答“当天推进了什么、卡在哪里、次日建议做什么”；不替代 `docs/00-governance/project-status.md` 的项目级主状态页，也不替代 `weekly-report-*.md` 的周度分析角色。

## 本目录看什么

- 每天新增或完成了什么
- 当天出现了哪些阻塞、风险或决策依赖
- 次日最值得继续推进的动作

## 本目录不再重复维护什么

- Sprint 全表、里程碑全表和长期路线图
- 项目整体 100% 进度这类稳定结论
- 大段测试总量、API 总量、错误码总量等周报级统计
- 已经在主状态页和周报中长期稳定存在的总结性文字

## 建议阅读顺序

1. 先看 `docs/00-governance/project-status.md`，了解项目级结论
2. 再看最近一份周报，了解周度趋势判断
3. 最后进入具体日期的日报，查看当天变化和阻塞

## 写法约束

- 日报以“当日变化”优先，而不是重复抄写项目全景
- 当天无本质变化时，应简洁说明“状态持平 + 原因 + 回链”
- 长期稳定结论应回链到主状态页、周报或自动推进日志
