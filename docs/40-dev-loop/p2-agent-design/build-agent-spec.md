# Build Agent 技术规范

> 文档状态：draft
> 适用阶段：P2（多代理协同期）
> 维护要求：持续维护

## 职责定义

Build Agent 负责打包客户端、服务端、内容包，管理版本和发布。

## 输入

| 输入来源 | 格式 | 说明 |
|---------|------|------|
| 代码分支 | Git | 通过门禁的分支 |
| 内容包 | JSON | 已审核通过的内容 |
| 版本配置 | yaml | 版本号和元数据 |

## 输出

| 输出产物 | 格式 | 说明 |
|---------|------|------|
| 客户端构建 | .exe/.apk | 游戏客户端 |
| 服务端镜像 | Docker | Docker 镜像 |
| 内容包 | zip | 打包的内容包 |
| 回滚包 | zip | 可回滚的版本包 |

## 核心流程

1. 检查代码分支是否通过门禁
2. 构建客户端
3. 构建服务端镜像
4. 打包内容包
5. 生成回滚包
6. 写入版本元数据

## 关键能力

- Godot 客户端构建
- Docker 镜像构建
- 内容包打包
- 版本管理

## 约束条件

- 必须遵循 42-release-rollback.md 规范
- 必须支持灰度发布
- 必须生成回滚包
- 版本号必须符合语义化规范

## 验收标准

- 客户端构建成功
- 服务端镜像构建成功
- 内容包打包成功
- 回滚包可用
