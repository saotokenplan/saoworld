# Gameplay Agent 技术规范

> 文档状态：draft
> 适用阶段：P2（多代理协同期）
> 维护要求：持续维护

## 职责定义

Gameplay Agent 负责编写 Godot 场景、角色控制、交互和任务逻辑。

## 输入

| 输入来源 | 格式 | 说明 |
|---------|------|------|
| design-note.md | markdown | 技术设计文档 |
| 现有场景 | .tscn | 当前场景文件 |
| 现有脚本 | .gd | 当前 GDScript 文件 |
| 数据配置 | json/yaml | 区域、任务、NPC 数据 |

## 输出

| 输出产物 | 格式 | 说明 |
|---------|------|------|
| 场景文件 | .tscn | Godot 场景 |
| 脚本文件 | .gd | typed GDScript |
| 测试文件 | .gd | GUT 测试用例 |

## 核心流程

1. 读取 design-note.md 和现有代码
2. 创建/修改场景文件
3. 编写/修改脚本逻辑
4. 编写测试用例
5. 运行测试验证

## 关键能力

- Godot 场景设计和实现
- GDScript 编程
- 角色控制和交互逻辑
- 任务系统实现

## 约束条件

- 必须使用 typed GDScript
- 场景文件与脚本文件同名
- 必须遵循 30-godot-client.md 规范
- 必须编写测试用例

## 验收标准

- 场景文件结构合理，节点命名清晰
- 脚本代码符合 typed GDScript 规范
- 测试用例覆盖核心逻辑
- GUT 测试全部通过
