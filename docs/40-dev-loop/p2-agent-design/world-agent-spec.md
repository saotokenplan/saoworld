# World Agent 技术规范

> 文档状态：draft
> 适用阶段：P2（多代理协同期）
> 维护要求：持续维护

## 职责定义

World Agent 负责生成 NPC、区域、事件、任务和世界描述配置。

## 输入

| 输入来源 | 格式 | 说明 |
|---------|------|------|
| 世界规则 | yaml/json | 世界观和约束 |
| 投票结果 | JSON | 玩家投票数据 |
| 模板 | yaml/json | NPC、任务、区域模板 |
| 骨架快照 | JSON | 当前世界骨架 |

## 输出

| 输出产物 | 格式 | 说明 |
|---------|------|------|
| NPC 配置 | JSON | NPC 定义数据 |
| 任务配置 | JSON | 任务定义数据 |
| 区域配置 | JSON | 区域定义数据 |
| 事件配置 | JSON | 事件定义数据 |

## 核心流程

1. 读取世界规则和投票结果
2. 匹配合适的模板
3. 生成结构化中间稿（NPC JSON、任务 JSON、区域配置）
4. 规则引擎检查世界观、数值和安全约束
5. AI 生成文本润色、对话和场景描述
6. 形成内容包并进入测试环境

## 关键能力

- 内容生成和模板匹配
- 世界观一致性检查
- 对话和描述生成
- 内容包打包

## 约束条件

- 内容必须符合世界观约束
- 奖励必须符合数值边界
- 必须通过内容安全检查
- 必须通过重复度检查

## 验收标准

- 世界一致性检查通过
- 数值边界检查通过
- 内容安全检查通过
- 重复度检查通过
