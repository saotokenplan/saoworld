# 玩家沟通资料入口

> 文档状态：active
> 适用阶段：对外沟通准备
> 维护要求：持续维护

## 目的

本目录用于收纳面向玩家或公测沟通场景的模板与说明材料，帮助团队统一公告、FAQ、新手引导和已知问题说明。

## 当前定位

- 本目录属于 `docs/40-dev-loop/` 下的过程支持资料。
- 本目录只承接沟通模板和说明材料，不替代产品规范、发布规范或客服系统中的正式公告记录。
- 具体对外口径应结合当前项目状态、发布计划和运营决策同步维护。

## 阅读建议

1. 发布前先查看 `announcement-template.md` 和 `known-issues.md`。
2. 面向新玩家的说明优先查看 `new-player-guide.md`。
3. 若涉及当前项目阶段或发布时间窗，先回查 `docs/00-governance/project-status.md` 与相关 runbook。
