# 运维操作 Runbook 入口

> 文档状态：active
> 适用阶段：当前
> 维护要求：持续维护

## 目的

本目录用于集中存放发布、部署、迁移、回滚和初始化等运维操作型 Runbook，帮助协作方按统一步骤执行高风险操作并保留明确的回滚路径。

## 当前定位

- 本目录是 `docs/40-dev-loop/runbooks/` 下的运维操作子目录。
- 本目录只回答“如何执行具体操作、如何验证结果、如何回滚”，不替代发布与回滚规范本身。
- 发布策略、状态机和工程约束以 `docs/20-specs/`、`.trae/rules/` 和相关服务规范为准。

## 使用建议

1. 执行前先确认操作对象、前置条件和回滚条件。
2. 按 Runbook 步骤逐项执行，并在关键步骤后记录验证结果。
3. 若出现异常，优先按同文档内的回滚方案处置，再回查相关规范。
