# 周度代码审查入口

> 说明：本目录用于保留每周代码审查、低风险重构和自动治理的结果摘要；不替代 `docs/00-governance/project-status.md` 的项目级主状态页，也不替代 `docs/40-dev-loop/weekly-report-*.md` 的周度业务分析角色。

## 本目录看什么

- 本周哪些代码区域最热、最值得审查
- 审查发现了哪些架构、可靠性、测试和维护问题
- 哪些低风险问题已经在本周直接修复
- 下周还建议继续治理什么

## 本目录不再重复维护什么

- Sprint 全景进度与里程碑总表
- 项目整体“已就绪/待发布”的主结论
- 大段业务周报式成果复述
- 与主状态页、周报重复的发布节奏判断

## 建议阅读顺序

1. 先看 `docs/00-governance/project-status.md`，了解项目级状态
2. 再看最近周报，了解周度成果与偏差判断
3. 最后看本目录的周度代码审查报告，了解代码层热点、缺陷和治理动作
