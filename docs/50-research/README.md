# 技术调研入口

> 文档状态：active
> 适用阶段：当前
> 维护要求：按需维护

## 目的

本目录作为 `docs/50-research/` 的统一入口，用于收拢技术选型、方案比较和历史决策依据，帮助协作方理解“为什么当时这样选”，而不是把调研文档当作当前执行规范。

## 适用范围

- 适用于回顾引擎、服务端、基础设施和工程工具链的选型背景。
- 适用于后续复盘历史决策、重做技术评估或补充替代方案比较。
- 不替代 `docs/20-specs/` 的现行实施约束。

## 当前定位

- 本目录承担参考层和归档层职责。
- 本目录重点保留结论、依据、比较过程和外部资料引用。
- 若本目录与现行规范冲突，应以 `docs/20-specs/` 和治理文档为准。

## 使用建议

1. 需要快速落地时，优先看 `docs/20-specs/`
2. 需要理解历史决策原因时，再回看本目录
3. 新调研应尽量输出明确结论，并避免在调研文档中直接承载正式规范
