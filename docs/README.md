# 文档目录说明

## 目录结构

- `requirements/`
  - 游戏需求与方案拆分文档
  - 适合先看这组，快速了解项目目标、功能和技术边界
- `dev-loop/`
  - AI Coding 研发闭环、Loop Engineering 与门禁配套文件
  - 适合做工程落地和仓库初始化时使用
- `research/`
  - 技术选型与服务端技术栈调研
  - 适合做引擎、后端和基础设施决策时参考
- `specs/`
  - 基于前面讨论继续细化出的详细规范包
  - 适合直接作为拆任务、建仓库和写代码的输入
