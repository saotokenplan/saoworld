# game/ - Godot Client

Godot 4 + typed GDScript client project.

Directory structure per `engineering-conventions.md`:
- `project.godot` - Godot project file
- `scenes/` - Scene files (.tscn)
- `scripts/` - GDScript files
- `data/` - Static data files (JSON/resources)
- `assets/` - Images, audio, and other assets
- `tests/` - GUT test scripts

Not yet initialized. Run `godot4 --editor` here to create the project.
